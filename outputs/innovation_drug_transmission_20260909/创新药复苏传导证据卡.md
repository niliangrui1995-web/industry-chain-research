# 创新药复苏传导：CRO 与 CDMO 证据卡

研究截止：2026-09-09，Asia/Shanghai。所有增速均为公司2026年半年度报告披露的同比口径；订单、在手订单为公司经营披露，口径不统一，禁止横向计算 book-to-bill。

## 传导结构

资金/BD → 候选物发现 → IND-enabling（药效、DMPK、GLP安评）

同时并行：药学、工艺开发、稳定性、临床样品（早期 CMC/CDMO）

IND → I/II期临床运营、数据、中心实验室（临床 CRO）+ 临床供药 CDMO

III期/申报 → PPQ、放大、商业化供应（后期/商业化 CDMO）

## 2026H1 代表性证据

| 环节 | 公司 | 直接经营证据 | 当前状态 |
|---|---|---|---|
| 临床前 CRO | 益诺思 | 新签+175.56%，在手+80.09%，营收+23.92% | 订单已强、收入开始转化 |
| 临床前 CRO | 美迪西 | 新签+104.74%，营收+40.91%，临床前研究收入+52.26% | 订单、收入与扣非修复同步 |
| 临床前 CRO | 昭衍新药 | 新签+98.0%，在手+60.9%，营收仅+5.27% | 订单先行，主营利润尚未恢复 |
| 临床 CRO | 泰格医药 | 临床试验技术服务+20.68%；净新增订单增长加速 | 进入收入端，但历史低价订单压毛利 |
| 临床 CRO | 康龙化成 | 临床研究服务+13.75%；新签+超30% | 执行收入改善，毛利率仍下行 |
| 临床 CRO | 诺思格 | 临床技术服务+37.48%，毛利率-10.53pct | 收入改善快于利润/现金 |
| CDMO | 药明康德化学业务 | 化学业务+53.3%；小分子D&M+72.7% | 后期/商业化项目已兑现为收入和毛利 |
| CDMO | 凯莱英 | 在手+53.77%，新签+54.59%，营收+13.13% | 订单强于收入；后期项目交付有季节性 |
| CDMO | 博腾股份 | 临床后期及商业化收入+24.29%；临床早期收入-28.57% | 后期复苏、早期仍分化 |
| CDMO | 九洲药业 | 营收-10.30%、扣非-26.56%，但项目及部分订单增加 | 订单尚未普遍转为收入/现金 |

## 结论边界

- 最早对新项目资金改善作出反应的是药物发现、IND-enabling CRO 与早期 CMC；这不等于临床前 CRO 是唯一受益者。
- 临床 CRO 已进入订单、项目执行和收入恢复阶段，但低价历史订单、人力成本和项目结构使利润率滞后。
- 早期 CMC 和临床样品 CDMO 与临床前阶段并行；后期/商业化 CDMO 的已兑现收入可能更强，但其中包含历史在手、已有商业化品种和产能爬坡，不能全部归因于本轮创新药复苏。
- 因此，当前最准确的结论是：订单端已覆盖IND前、临床和CDMO；收入端在临床前和临床CRO仍有明显分化；利润端尚未全链条修复。
