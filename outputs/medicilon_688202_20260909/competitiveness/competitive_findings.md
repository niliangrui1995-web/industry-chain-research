# 美迪西竞争力研究分项

研究截止：2026-09-09，Asia/Shanghai。主体：上海美迪西生物医药股份有限公司，688202.SH，A股，报告币种人民币。仅处理服务竞争力，不形成估值或买卖意见。

## 核心判断

`inference`：美迪西具有真实的临床前综合交付能力，较突出之处是免疫肿瘤/ADC项目积累、药效模型、药代与安评衔接以及跨国申报经验。可评为国内有竞争力的临床前综合CRO，但现有证据不足以认定其在规模、独占技术、持续定价权或全球交付网络上优于药明康德、康龙化成，也不能将AI、NAMs平台名称当作独占护城河。

`official_fact`：2025年报p15定义，公司移交研究成果和数据，主要收研究服务费，采用FTE和FFS。因此客户ADC/GLP-1药品获批、出海和未来放量，主要通过新增研发项目和服务环节传导，不能把客户药物销售额或BD总额视为美迪西的收入权益。未发现自动分享合作药品销售提成的普遍商业模式。

## 服务能力与成熟度

| 方向 | 已披露的能力或经营事实 | 竞争含义及限制 |
|---|---|---|
| 药物发现 | H1 p13-14、18-19：合成/药化、筛选、结构生物学、PROTAC、mRNA展示环肽筛选，连接子及载荷合成 | 有完整实验链条，可减少跨供应商协调。但药明、康龙有同类能力；没有统一基准证明合成成功率、周期、单价或净留存更好 |
| 药学/CMC | H1 p13：原料药、晶型/盐型、杂质、工艺、制剂和分析检测；胶束/脂质体/LNP，正在拓展纳米抗体制剂 | 一体化有利于承接IND项目，不能直接升级为大规模商业化CDMO龙头。药学与发现合并披露，难以分拆利润贡献 |
| 临床前/安评 | H1 p11-12、14-16：约2.9万平方米GLP实验室、9项GLP服务，2026年5月NMPA定期复查；药效模型接近1,100种，含800种肿瘤模型 | 数据可靠、质量体系、特定疾病经验是客户付费原因；GLP资质形成准入门槛，但头部同行同样具备，不是美迪西独占 |

| 双载荷ADC | H1 p18提及双载荷连接体设计合成；p40新的完整双载荷抗体偶联项目为初步研究阶段 | 子模块经验不等于全流程平台已完成。p40已本地渲染肉眼核对 |
| AI | H1 p23：ADMET/PK及siRNA/ASO平台迭代部署；p41 AI-PROTAC新项目仍数据平台与模型架构设计 | 既有已部署工具，也有早期在研工具。未发现独立对照验证的研发成功率提升、AI独立收入或新增订单贡献 |
| NAMs/类器官 | H1 p32：肝癌细胞2D/3D体系初步方法学验证；p36 NAMs-PBPK新项目仍调研、初步干湿实验方案。官网列出类器官/体外安全性/PBPK服务 | 属于转型准备与新服务潜力，不能认定监管已接受其平台全面替代动物试验。未见按特定用途验证的监管采纳率 |
| 海外交付 | H1 p11、14、16：波士顿研发中心已提供临床前服务，2026年6月通过AAALAC | 国际客户接近性改善；AAALAC主要是动物关怀/使用体系认可，不应等同于FDA批准全套研究。海外客户收入不等于美国本土实验室收入；波士顿单独收入、利用率、利润未披露 |

以上“已披露能力”以公司法定报告为证，技术先进性、国际领先、缩短研发周期等仍归类`management_claim`，未独立复现。IND获批是进入人体临床阶段，不是上市或临床成功。

## 最强反证与未来需求变化的竞争影响

1. `official_fact`：FDA于2026-03-18发布NAMs验证指导草案，强调预定用途、人体相关性、技术可靠与可重复性、适用于监管决策；并非“有类器官就可替代”。2026-05-29另就肿瘤生物药及偶联药发布简化安评草案，某些情况下可减少种属或以证据权重分析替代部分非人灵长类试验。`inference`：该方向直接影响美迪西已有ADC/安评优势，不宜仅当正面催化；单位项目动物试验收入可能受压，同时体外/建模需求增加，净影响取决于新服务变现能力。
2. `inference`：AI若减少每个候选分子的合成、筛选轮次，FTE工时需求也可能下降；只有项目总量、客户份额、服务附加值增长更快，才净利好CRO。AI新药客户合作不能自动证明美迪西自研AI模型领先。
3. `official_fact`：各头部竞争者均拓展新分子与NAMs。`inference`：终端赛道繁荣不保证美迪西份额或定价；它要靠更可靠的交付、跨环节协同、模型适配及客户关系赢得合同。
4. `inference`：GLP与申报经验形成技术/流程壁垒；项目中途切换供应商有迁移和重新验证成本，但新项目可以重新招标。没有足够数据把客户名单/获奖认定为永久锁定。

## 下一步最有价值的证据

- 按ADC、多肽/GLP-1、小核酸、传统小分子分拆的新签订单、执行金额、回款与毛利，而不只是累计IND数量。
- 同类型项目真实报价、交付周期/延误率、重复实验率、客户留存与每客户收入。
- NAMs/AI具体用途的独立验证、监管实际接受案例、单独付费客户与收入；分开成熟工具和新增研发项目。
- 波士顿实验室真实交付收入、成本和利用率，以及中美双报业务回款表现。
- 新增人员和实验室投产是否由已签可执行订单覆盖，防止短期回暖触发过度扩产。
