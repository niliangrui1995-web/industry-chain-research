# 投研方法检查表

仅在复杂产业链、公司深研或股票排序任务中读取。按问题裁剪字段，不要求每次填满所有表格。

## 需求传导

沿下列链条验证，不从热门股票反推故事：

```text
终端需求 -> 下游应用/客户 -> 公司产品或服务 -> 量/价/份额/利用率 -> 收入/利润/现金流
```

优先回答：

| 字段 | 核心问题 |
|---|---|
| 核心产品/服务 | 哪个具体产品、规格、业务线或服务驱动判断？ |
| 下游应用/客户 | 谁实际消耗或支付？ |
| 需求驱动 | capex、出货、使用量、替换周期、政策、价格或其他变量是什么？ |
| 同链验证 | 客户、同行、订单、积压、产能、利用率、库存或交付是否印证？ |
| 公司证据 | 收入、订单、认证、客户、产能、良率或份额证据是否足够？ |
| 财务传导 | 需求如何变成销量、ASP、结构、毛利率或经营杠杆？ |
| 时间与反转 | 兑现窗口和最早反转信号是什么？ |

## 价格与单位经济

当业绩依赖核心产品价格、ASP、ARPU、take rate、费率、利差、利用率或单位收入时，检查：

- 公司实现价和销量，排除产品结构造成的假涨价；
- 外部现货、合同、渠道、客户或同业价格信号；
- 原料、人工、算力、折旧、融资或交付成本；
- 单位价差/毛利率是否同步改善；
- 供需、认证、竞争或监管机制；
- 持续性属于结构升级、合格供给短缺、需求提价、周期、成本推动、经营杠杆、拉货或竞争降价中的哪一种；
- 价格、利润率、利用率、库存、流失率或新产能中的反转指标。

## 瓶颈判断

瓶颈必须同时有需求证据和合格供给约束。可用证据包括：分配、交期拉长、涨价、未满足订单、下游爬坡延迟、良率限制、认证队列、可用产能短缺或第二供应商导入滞后。

若只有技术难度、集中度、价值量、毛利率或国产替代难度，标为 `strategic_node`、`pricing_power_node` 或 `watch`，不要升级为瓶颈。

对确认的瓶颈继续回答：精确短缺对象、相邻产能为何不能替代、扩产/良率/认证路径、预计缓解窗口、置信度和反转指标。

## 公司映射

先选节点，再验证候选：

| 检查 | 通过条件 |
|---|---|
| 准确暴露 | 产品或收入直接对应目标节点 |
| 客户证据 | 客户、订单、认证、项目或可信供应链证据存在 |
| 重要性 | 暴露足以影响收入、利润或估值，而非边缘业务 |
| 兑现能力 | 产能、良率、代际、交付和资金能力支持兑现 |
| 财务确认 | 毛利率、现金流、应收和库存不明显反驳逻辑 |
| 反转条件 | 明确需求、价格、竞争、替代、客户或扩产风险 |

候选可分为 `main_candidate`、`watch`、`event_trade_only`、`theme_adjacent`、`reject`。不要为凑数强行给出三家公司。

## 三层排序

只在用户要求股票比较、排序或交易判断时使用：

| 层级 | 核心问题 |
|---|---|
| 基本面质量 | 壁垒、价值量、客户质量、利润与现金流是否可持续？ |
| 业绩弹性 | 产业变化能否转成收入、毛利率和利润？ |
| 交易弹性 | 市值、流通盘、流动性、趋势、催化、预期差和拥挤度是否支持较大股价反应？ |

三层可以得出不同第一名。高交易弹性但业务证据弱的公司只能是事件交易候选。

## 输出裁剪

复杂任务优先包含：结论、证据等级、需求传导、瓶颈/公司映射、三层排序（如适用）、最大风险和 3-5 个跟踪指标。快速问题压缩为要点，不复制完整模板。
