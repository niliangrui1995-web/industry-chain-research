# 工具与证据边界

仅在选择外部数据、MCP、浏览器、插件或写入型工具时读取。本文件按能力类别管理边界，不维护容易过期的全量工具名单。

## 证据等级

| 等级 | 典型来源 | 可支持内容 |
|---|---|---|
| `confirmed_official` | 公告、交易所、公司 IR、财报、招股书、监管或官方客户/供应商材料 | 硬事实和公司受益证据 |
| `credible_secondary` | 有具名来源的主流媒体、行业协会、可靠数据商或研究机构 | 交叉验证和行业背景 |
| `market_data_vendor` | TDX、iFinD、HTSC、东方财富、Yahoo、Alpha Vantage 等 | 行情、估值、流动性、技术和时间上下文 |
| `secondary_trading_context` | 概念标签、涨停原因、情绪、资金与交易结构摘要 | 搜索线索和市场关注度 |
| `lead_only` | Grok/X、Gemini、论坛、匿名截图、模型或无原链摘要 | 待核验线索 |

工具的品牌不决定证据等级；只有工具直接返回原始官方文件时，相关文件本身才可按官方来源使用。

## 能力类别

| 能力 | 使用边界 |
|---|---|
| 原生 web / 搜索 | 当前事实和官方来源优先；技术问题使用官方文档；重要结论给可追溯链接。 |
| TDX / iFinD / HTSC / 东方财富 / Yahoo / Alpha Vantage | 作为行情或厂商数据；不能单独证明客户、订单、收入或真实受益。 |
| 本地 HT/TongdaXin 文件 | 仅盘后本地快照和候选池；遵守 `ht-local-market-data` 的隐私与只读边界。 |
| Grok/X / Gemini 网页 | 发现实时线索、补来源或找反证；模型结论、目标价和因果解释不直接进入最终结论。 |
| Chrome / Browser / Playwright | 登录态网页优先使用用户已登录的 Chrome；Browser/Playwright 仅按任务需要，不冒充同一登录态。 |
| 文档 / 表格 / PDF / PPT | 使用当前会话已安装的专用技能或插件；保留格式、公式和编码，不在项目内复制上游技能。 |
| Public Equity 工作流 | 只在用户需要 thesis、catalyst、scenario、position risk、model 或正式 memo/deck 时使用；不替代产业链和证据判断。 |

## 写入与账户硬门

- 查询通常可按任务范围只读执行；改变外部 watchlist、模拟组合、订单、消息、日历、云文件或自动化必须有明确用户指令。
- 不因工具已安装就推定用户授权写入。
- 不打印、复制或落盘 API key、cookie、账户、密码、订单或无关日志。
- 外部写入完成后必须回读或用等价方式验证结果。

## 选择原则

优先使用能直接回答问题的最窄工具。不要同时调用多个等价行情源或搜索源来展示覆盖面；只有数据冲突、缺口或高风险结论需要交叉验证时再增加来源。
