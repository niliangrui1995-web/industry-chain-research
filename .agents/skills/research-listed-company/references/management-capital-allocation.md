# 管理层、治理与资本配置

管理层是核心投资变量、公司由创始人强驱动，或治理/资本配置可能改变结论时读取。

## 先确认决策者

区分头衔、实际控制人、经济权益、投票权和实际决策权。创始人卸任不等于失去影响；职业经理人任职也不等于掌握资本配置。

## 承诺兑现账本

只有明确、可衡量、有期限且可在公开材料中复核的承诺进入账本。愿景、目标口号和行业判断不进入兑现率分母。

| 字段 | 要求 |
|---|---|
| `commitment_id` | 稳定标识 |
| `original_wording` | 合规短引或准确转述 |
| `announcement_date` / `deadline` | 原始日期与承诺期限 |
| `scope` | 收入、利润、产能、回购、产品或其他 |
| `source` | 股东信、公告、财报会等原始出处 |
| `revision_or_walkback` | 后续修改、延期或撤回 |
| `actual_outcome` | 到期后的可核验结果 |
| `status` | `delivered | partial | missed | revised | not_due | unresolved` |
| `confidence` | `high | medium | low` |

不使用 80%/60%/40% 等固定阈值，也不把不同难度和外部条件的承诺机械平均。

## 困难时期与诚信

检查管理层在业绩 miss、监管、产品事故、流动性、竞争和股价压力下是否及时披露、正面解释、承担内部责任并采取可复核行动。员工评论、论坛和社交口碑只能作 `lead_only`。

只有监管处罚、审计结论、司法材料、正式治理文件或多项相互独立的强证据，才可以触发诚信硬否决。

## 资本配置账本

逐项记录并购、回购、分红、增发、债务、新业务投资和资产处置：宣布理由、融资方式、交易价格、当时估值、机会成本、事后经营结果、减值/退出和每股价值影响。

重点检查：

- 回购是否发生在低估而非仅抵消 SBC；
- 并购增长是否伴随商誉、债务和整合风险；
- 资本开支属于维持性还是增长性；
- 新业务是否长期吞噬现金但缺少里程碑；
- 分红是否挤压必要投资或依赖举债。

## 治理与接班

检查关联交易、薪酬、SBC 稀释、减持、双重股权、董事会独立性、审计意见、关键人风险和继任者准备。最终给证据与风险，不输出人格类型或固定综合分。
