# 上市公司研究方法

复杂公司深研、少量标的比较或投资备忘录需要完整推理链时读取。

## 信息质量与投资确定性

- 资料多只表示可核验材料丰富，不能证明生意更好或市场未定价。
- 资料少时只回答底层可验证问题：客户是谁、为何付费、替代品是什么、复购靠什么、竞争者投入资本能否复制。
- 每项推算写假设、方法、置信度和推翻它所需的新证据；无法合理推算就写 `N/A`。

## 生意与利润桥

用一句话定义生意，然后验证：

```text
终端需求 -> 客户任务 -> 产品/服务 -> 销量/ASP/份额/利用率
-> 毛利率/费用率/资本强度 -> 自由现金流与股东回报
```

至少回答：

- 客户为什么购买，预算来自哪里，谁有替代方案；
- 收入是一次性、订阅、复购、交易抽成还是周期价格；
- 增长来自销量、价格、结构、并表、汇率还是会计变化；
- 维持增长需要多少营运资本、资本开支、研发和渠道投入；
- 哪个变量最先反转，反转会经过多长时间传到利润。

## 真实暴露与商业化阶段

按 `研发计划 -> 送样/验证 -> 客户导入/design win -> 认证 -> 量产 -> 出货 -> 收入 -> 利润/现金流` 逐级确认。只允许在证据支持的最高一级停留；不得由相邻产品、同类客户或概念标签跨级。

公司暴露至少检查：准确产品、下游应用/客户、收入重要性、合格产能、良率/代际、交付、竞争替代和财务确认。

## 可证伪护城河

| 类型 | 支持证据 | 反证问题 |
|---|---|---|
| 定价权 | 提价后销量/留存、单位利润仍稳定 | 涨价是否只是供给周期或产品结构 |
| 转换成本 | 迁移时间、认证、数据/流程锁定 | 客户是否正推进双供或标准化 |
| 网络效应 | 参与者增加使产品价值提升 | 规模是否只增加成本和补贴 |
| 规模/成本 | 单位成本、采购、渠道、资本效率 | 竞争者是否可通过资本快速复制 |
| 技术/资源 | 客户验证、性能/良率、稀缺资源 | 领先是否依赖单一代际或保护期 |

必须判断过去 3-5 年趋势以及未来摧毁条件。高毛利、高市占率和高研发投入本身不是护城河。

## 反方与估值连接

先写最强、最有证据的空头论点，再写反证。至少覆盖：需求误判、竞争/替代、客户集中、技术代际、监管、资本配置、财务质量和估值过度定价。

情景使用 `base / adverse / severe`，每个情景写清经营假设、现金流影响、市场隐含预期和失效条件；不使用跨行业固定增长率或 PE 阈值。

## 比较与输出

只有用户要求比较时才排序，并分开：

- 基本面质量；
- 业绩弹性；
- 估值与预期差；
- 交易弹性。

四层可以有不同第一名。高交易弹性但业务证据弱的公司只能是事件交易候选。
