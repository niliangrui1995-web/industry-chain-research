# 收益型投资行业指标

在选择派息覆盖口径时读取。优先使用监管、法定或行业通行定义，并解释公司披露口径。

| 类型 | 必查指标 | 常见陷阱 |
|---|---|---|
| 普通公司 | 母公司法定可分配利润、经营现金流、维持性资本开支、净债务、利息覆盖、稀释 | 只看合并 EPS payout；忽略母公司现金和资本开支 |
| 中国公募 REIT / REIT | 可供分配金额、FFO/AFFO、出租率、租约期限、LTV、运营方、关联交易 | 用 EPS 判断覆盖；忽略资产维护和租约集中 |
| 银行 | CET1、资本缓冲、可分配利润、资产质量、信用成本、净息差、监管限制 | 只看利润增速和 payout，不看资本消耗 |
| 保险 | 偿付能力、资本生成、母公司现金、准备金、灾害/市场风险 | 把会计利润等同可分配现金 |
| BDC | NII、NAV、non-accruals、杠杆和融资成本 | 高收益掩盖资产质量恶化 |
| 资源股 | 中周期商品价格、维持性资本开支、净现金/债务、浮动分红政策 | 用周期顶部现货价格外推永久股息 |
| 电信/公用事业/基础设施 | 维持性与增长性资本开支、利息覆盖、债务期限、监管回报 | 把全部 capex 当增长投入或忽略再融资 |

如果公司同时跨多个类型，分别计算后再解释，不选择最有利口径。
