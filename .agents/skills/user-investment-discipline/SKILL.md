# User Investment Discipline

把本技能作为用户个人市场周期与情绪纪律，只在明确命中场景时使用。它不是上市公司、产业链、财报、估值或收益型研究入口，也不是已被普适验证的交易定律。

## 执行方法

1. 明确指数或证券、市场阶段、时间窗口，以及“跌破”“大跌”“双头”和量化信号的定义。
2. 指出“这触及你此前总结的第 X 条”。
3. 用当前行情和多维历史样本判断证据是支持、反驳还是不足。
4. 给出反证、失效条件和数据缺口，不自动导出买入、卖出、减仓或加杠杆动作。

## 用户市场周期启发式

1. 牛市主升浪中，指数首次跌破 MA30 时高度重视。若短期再创新高，关注随后单边下跌或围绕首次跌破低点横盘；若不再创新高，关注直接进入中级调整。用户记录的三个单边下跌样本为 `19—20%—24.26%`、`14—22%—33%`、`13—21%—28%`，但时间单位和样本定义未注明，确认前不得转成概率预测。
2. 牛市主升浪出现用户所称“量化信号”时，短期仍可能再创新高；熊市或弱市中可能需要两次以上信号才止跌。没有信号定义时不臆测公式或阈值。
3. 牛市主升浪出现双头，或长假后第一个交易日大跌时，提高风险警戒。
4. 牛市中级调整结束并确认进入下一轮主升浪时，优先检查前期涨幅较少或新爆发的核心板块；“核心”和“确认”仍须产业与市场证据。

## 情绪纪律硬门

当市场或持仓连续快速上涨，并且用户表现出兴奋、贪婪、膨胀、追涨、扩仓或加杠杆冲动，或者主要依赖任一单项指标推导确定性结论时，必须在结论或风险段逐字附上：

> 当你涨的浑身燥热时，很贪婪，很膨胀的时候，一定要回顾历史，确定当下市场在历史中所处的位置，不要迷信任何一个单一指标，比如基本面，每一次都一样！！！

命中后比较当前与历史的相似和不同，写明样本、指标、时间、反证和证据缺口。数据不足时写 `N/A`，不补造历史分位。
