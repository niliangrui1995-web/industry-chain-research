# TDX Finance Data 边界

TDX 自然语言行情接口用于交易和厂商数据上下文，不用于证明公司客户、订单、收入或产业链真实受益。典型调用形态为 `tdx_wenda_quotes(question, range, page, size)`。

## 市场范围

- `AG`：A 股，默认。
- `HK-GP`：港股。
- `JJ`：基金和 ETF。
- `ZS`：指数、通达信板块或指数代码。

返回通常包含 `meta`、`headers` 和 `data`。必须记录返回表头里的交易日期；它不保证是实时数据。

## 适用范围

- 单一证券最新行情、成交、换手、市值、PE/PB 和近期价格行为；
- MACD、KDJ、RSI、均线、量比等技术上下文；
- 查询能清晰映射时的财务快照，但仍是厂商数据；
- 指数/板块行情、概念或行业成分初筛、涨跌停与原因揭秘；
- 基金/ETF 净值和交易字段、港股快速行情。

## 不适用范围

- 官方公告、交易所文件、财报、IR、客户或供应商原始证据；
- 完整研报、分析师论文或可审计的研究结论；
- 未经当前验证的资金流、北向或主力流入字段；
- 一次调用完成多证券严谨比较；
- 全市场精确宽度统计、长期 OHLCV 仓库、因子回测或 VCP 研究。

## 证据和查询纪律

- 价格、估值、成交、技术、指数和基金字段标为 `market_data_vendor`。
- 涨跌停原因、板型、连板、封单和概念标签标为 `secondary_trading_context`。
- 一次查询一个证券、基金、指数、板块或筛选；比较时分别查询后合并。
- 尽量同时给 ticker 和名称；指数/板块用 `ZS`，基金/ETF 用 `JJ`。
- 返回空集时先缩短问题并减少混合维度，再判定缺失。
- AI/半导体概念名单只用于发现线索，随后必须用官方披露和产业链证据验证真实暴露。
