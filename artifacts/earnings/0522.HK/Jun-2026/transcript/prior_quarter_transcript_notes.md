# ASMPT Q1 2026 电话会记录工作笔记

来源：[Roic AI Q1 2026 transcript](https://www.roic.ai/quote/0522.HK/transcripts/2026-year/1-quarter)，类型为 `third_party_transcript`；上一季度[官方原始音频](https://www.asmpt.com/site/assets/files/85245/asmpt_q1_fy2026_investor_conference_call_audio.mp3)可用，但本次未做全量 ASR。

## 与本次判断有关的上一季度表述

- Memory TCB：管理层称上一笔主要 bulk order 在上年 Q4，客户购买时点存在波动；独家联合评估仍在推进。该表述为本季“HBM4 rollout 决定新设备采购时点”的比较基线。
- CPO / Hybrid Bonding：管理层把 TCB、HB 和 photonics 视为不同集成路径中的可替代或互补方案，没有把 HB 的评估直接等同量产订单。
- 上游交付：管理层称 SMT 收入转化受到供应商交期影响，团队正在处理并期待 H2 改善；SEMI 同样偏紧但当时称仍可管理。
- Photonics：管理层强调增长来自较小基数。当前季度“1H 收入近三倍”的表述仍需结合这一基数限制解读。

## 使用边界

- 仅用于上一季度管理层语气、承诺和 Q&A 基线。
- 未用第三方记录替代当前季度电话会；当前季度 Q&A 仍为 `evidence_absent`。
- 不把匿名客户描述升级为可核实客户名称，也不把联合评估升级为订单或量产。
