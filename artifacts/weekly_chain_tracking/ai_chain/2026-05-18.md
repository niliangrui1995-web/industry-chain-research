# 周度总览：AI产业链上下游雷达

报告日期：2026-05-18
覆盖窗口：2026-05-10 至 2026-05-18
任务目录：`artifacts/weekly_chain_tracking/ai_chain/`

## 结论先行

- 本周全链最明确硬堵点仍是 `HBM / AI memory / enterprise SSD`，证据链由 Micron、Samsung、TrendForce 与 CoreWeave 的 AI cloud 需求共同支撑。需求超过合格 DRAM/NAND/HBM 供给不是概念热度，而是已经体现在价格、供应分配、客户长期锁量和供应商 capex 节奏上。
- 光模块专项已把 `高端 EML / InP / CW laser / pump laser` 维持为硬堵点。本周不重复展开细节，但在全链排序中继续排在第二梯队核心卡点。
- AI PCB 专项把 `M7/M8 CCL/prepreg` 维持为软堵点，把 `高端电子布 / Low CTE / T-glass / Low Dk/Df` 强化为 `soft_bottleneck+`。本周全链只吸收其结论并纳入横向排序。
- 新增最值得继续深挖的是 `数据中心电力 / 液冷 / rack power / 预制化基础设施`。CoreWeave 的 backlog 与 active power、Eaton/Schneider/Vertiv 的订单和产能扩张都证明需求强，但单品级变压器、switchgear、CDU、冷板、rack PDU 交期仍不够，暂不升为硬堵点。
- `CoWoS / advanced packaging / 半导体设备` 本周由 Applied Materials 新证据强化结构重要性，但缺新增“合格产能不足、客户排产延迟、交期拉长”的硬证据，维持 `strategic_watch`。
- 本周深挖方向：1）HBM/AI memory/enterprise SSD；2）数据中心电力/液冷/rack power。光模块和 PCB 由专项覆盖，仅吸收结论。
- 最大证据缺口：缺客户 allocation 细表、单品交期、合格产能、客户 AVL/认证名单和 A 股订单纯度；这些缺口决定是否把多个 `watch` 升级成 `soft_bottleneck` 或 `hard_bottleneck`。

## 本期深挖方向

1. `HBM / AI memory / enterprise SSD`
   目标：确认当前最硬约束是否延续到 2027H1/2027H2，尤其是 HBM4/HBM4E、DRAM 晶圆分配、advanced packaging for HBM、enterprise SSD/KV cache offload 是否共同挤压可用供给。

2. `数据中心电力 / 液冷 / rack power / 预制化基础设施`
   目标：把 strong backlog 拆成单品层面的变压器、switchgear、UPS、rack PDU、busway、CDU、冷板、quick connector、预制模块、并网和工程交付约束，避免把“需求强”误判为“现成短缺”。

## 最大风险

- AI capex 节奏被融资、监管、电力并网或客户 ROI 反噬，导致上游锁单变成库存风险。
- HBM/DRAM/NAND 扩产与二供认证快于预期，价格高位反转。
- 光源/InP 6 英寸产能和客户二供兑现，allocation 解除，光模块上游硬堵点转为正常高景气。
- CCL/电子布/HVLP 只有涨价和概念，缺真实成交价、交期和客户 AVL，导致 A 股交易弹性先行但业绩兑现不足。
- 数据中心电力/液冷仍停留在需求强和 backlog 强，若单品交期补不出来，不能升为硬堵点。
- A 股映射中订单纯度、海外客户、收入占比和毛利贡献不清，容易从“真受益”退回“主题映射”。
