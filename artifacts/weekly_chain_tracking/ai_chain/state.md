# 周度总览：AI产业链上下游雷达 - 滚动状态

## 任务边界

本任务负责 AI 产业链横向雷达和赛道优先级，不重复展开光模块和 AI PCB 专项的细节。执行时必须读取：

- `artifacts/weekly_chain_tracking/optical_module/state.md`
- `artifacts/weekly_chain_tracking/ai_pcb/state.md`

如果两个专项已有最新状态，本任务只吸收其结论并做全链横向排序。

研究宇宙：

- 云厂商 / AI CapEx / 数据中心建设。
- GPU / ASIC / 加速卡。
- HBM / DRAM / 存储。
- 先进封装 / CoWoS / SoIC / 封装设备材料。
- ABF / BT / 封装载板。
- AI PCB / CCL / 上游材料。
- 光模块 / 硅光 / CPO / OCS / 光互连。
- 交换机 / 以太网 / InfiniBand / DSP / retimer / NIC / DPU。
- 液冷。
- 数据中心电力：变压器、开关柜、UPS、母线、PDU、rack power。
- 服务器 / ODM / 连接器 / 关键材料与设备。

## 首次运行要求

首次执行时，请使用 `BASELINE_TEMPLATE.md` 建立第一期报告，并完成：

1. 先建立全链节点地图。
2. 从全链角度识别 3-5 个最值得跟踪的堵点或潜在卡点。
3. 从中选择最多 1-2 个深挖，其余进入观察池。
4. 不替代光模块和 AI PCB 专项；只做横向优先级和卡点迁移判断。

## 候选观察池

以下只是首期需要检查的候选赛道，不是当前结论：

| 候选赛道/节点 | 需要验证的堵点问题 | 不可直接下结论的原因 |
|---|---|---|
| HBM / 高端 DRAM | 是否存在合格产能、封装配套、客户锁定或良率导致的供需缺口 | 高需求不等于所有存储环节都短缺 |
| CoWoS / 先进封装 | 是否存在封装产能、设备、材料或客户排产卡点 | 需区分当前产能瓶颈和未来扩产消化 |
| ABF / BT 封装载板 | 是否存在封装载板合格供给或良率瓶颈 | 不能与板级 AI PCB 混同 |
| AI PCB / CCL / 材料 | 专项任务结论是否显示高端材料或高层板制造卡点 | 全链任务只吸收结论，不重复展开 |
| 光模块 / CPO / OCS | 专项任务结论是否显示光芯片、光引擎、DSP 或封装测试卡点 | 全链任务只吸收结论，不重复展开 |
| 数据中心电力 | 是否存在变压器、开关柜、UPS、并网或 rack power 交付瓶颈 | 电网瓶颈可能延迟下游建设，也可能利好设备商 |
| 液冷 | 是否存在 quick connector、冷板、CDU、泵阀、可靠性认证卡点 | 液冷渗透提升不等于每个部件都短缺 |
| 连接器 / 高速互连 | 是否因高速率、可靠性、客户认证形成合格供应商瓶颈 | 需验证具体产品代际和客户 |
