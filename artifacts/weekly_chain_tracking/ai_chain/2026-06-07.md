# 周度总览：AI产业链上下游雷达

报告日期：2026-06-07  
覆盖窗口：2026-05-31 至 2026-06-07，北京时间  
任务目录：`artifacts/weekly_chain_tracking/ai_chain/`

## 结论先行

- 本周全链最硬约束仍是 `HBM / server DRAM / NAND / enterprise SSD / AI server parts supply`。HPE Q2 FY26 给出 record AI backlog 与新 AI Systems orders；Broadcom Q2 FY26 给出 AI semiconductor revenue 与 next-quarter step-up；TrendForce 6/1-6/2 把 DRAM/HBM 供需和定价权继续推高。Dell 上周的 parts supply 约束不是孤立个案，本周被 HPE 的 DRAM/NAND inflationary costs and supply constraints、Broadcom secure supply/inventory、TrendForce HBM/DRAM 数据继续强化。
- `高端 EML / InP / CW-DFB / pump / ELS / 1.6T 光互连组件` 继续吸收光模块专项，维持 `hard_bottleneck`。本周 TrendForce 6/3 明确 NVIDIA、Google、Meta 等锁定 EML/CW-DFB LD 产能，EML 与 CW-DFB LD 2026 年合计月产能扩大至约 5,070 万颗；Ciena Q2 FY26 和光模块专项继续指向 optical/networking demand 高景气且供应环境受约束。
- `M7/M8/M9/M10 CCL / prepreg + 高端电子布 / HVLP` 继续吸收 AI PCB 专项，维持 `soft_bottleneck+`。台光电、台燿、联茂等 5 月营收和涨价/lead time 线索验证需求和价格传导，但 HVLP4/5、Q cloth/石英布、板厂良率/测试仍缺足够 A/B 级硬短缺证据。
- `数据中心电力 / 并网 / transformer / switchgear / UPS / busway / rack power / 800VDC / 液冷` 维持 `soft_bottleneck`，其中 PJM/Ohio/PA 类区域电力仍按 `regional hard operational bottleneck` 处理。本周 NVIDIA DSX、FERC large-load docket、Ohio 6/1 testimony、JLL 2026 outlook、Infineon/EPC 800VDC/MGX 证据把电力/并网/设备交付和 rack-level power 迁移继续推高，但不把所有 transformer/switchgear/CDU 升为全球 hard，因为单品 allocation 与交期仍不完整。
- `CoWoS / SoIC / EFB / advanced packaging / substrate` 维持 `soft_bottleneck/watch+`，不升 hard。Broadcom/Marvell/NVIDIA/custom ASIC 需求强、HBM 位元需求强，但本周仍缺 TSMC/OSAT 官方交期、allocation、良率或客户排产延期。
- 本周进入全链排序的 5 个细分赛道：1）HBM/DRAM/NAND/eSSD + AI server parts；2）高端光源与 1.6T 光互连；3）AI PCB/CCL/高端电子布/HVLP；4）数据中心电力/800VDC/rack power/液冷；5）custom ASIC / AI networking silicon / advanced packaging。
- 本周深挖 2 个方向：`HBM/DRAM/NAND/eSSD + AI server parts supply` 与 `数据中心电力/并网 + 800VDC/SST/rack power/液冷`。光模块和 PCB 已由专项 2026-06-07 覆盖，本报告只吸收结论并做横向排序。
- 本期未逐项刷新 A/H/台/美股最新价格、市值、PE/PB、换手率；涉及交易弹性只做定性排序，行情字段写 `N/A`。

## 最大风险

- 把 HPE/Dell 的 AI server 订单和 backlog 全部等同于立即可交付收入。当前证据更准确地指向：需求强、订单强，但 memory/parts/电力等节点会决定交付节奏。
- 把 Samsung HBM4E samples 误读成当前供给释放。送样是缓解路径，不是客户认证通过、量产 allocation 或价格回落。
- 把 Broadcom AI semiconductor 强需求直接当成 networking silicon 或 advanced packaging hard bottleneck。当前仍缺交期、allocation 和客户排产延期证据。
- 把 TrendForce 光源 lock-in/capacity expansion 误读为扩产已经解决短缺。扩产仍需 InP 良率、老化测试、客户认证和 capacity rights 兑现。
- 把 PCB/CCL 台系营收创新高等同于所有上游材料 hard。HVLP4/5、Q cloth/石英布、板厂良率/测试仍处于 watch 或 future bottleneck。
- 把区域电力 hard 扩大成全球所有 power equipment hard。FERC/Ohio/JLL 能证明区域/项目层级约束，单品 transformer/switchgear/CDU/UPS 仍需 lead-time/allocation。
