## 结论先行

- 本周全链最明确的硬堵点仍是 `HBM / server DRAM / LPDRAM / NAND / enterprise SSD / AI server parts supply`。HPE 官方 transcript 把 DRAM/NAND 成本和 supply constraints、AI systems backlog、memory availability 对 2027 转化节奏的影响升为 A 级证据；TrendForce 本周新增 enterprise SSD supply crunch 与 LPDRAM supply bottleneck，说明堵点已从 HBM 扩散到 server memory hierarchy 与 storage tier。预计持续 `2026H2-2027H1`，若 HBM4E/eSSD/LPDRAM/CPU/packaging ramp 慢，可延至 `2027H2`，置信度中高。
- `高端光源链：InP substrate / 6 英寸合格 InP 产能 / EML / CW-DFB / UHP pump / ELS` 继续作为当前 `hard_bottleneck`。本期吸收光模块专项 2026-06-14 状态：AXT SEC 文件把 InP 出口许可列为官方约束，TrendForce 与 Ciena 继续支持 AI 光互连需求和产能锁定。预计 EML/InP `2026H2-2027H1`，CW/ELS/UHP/InP 尾部可偏紧至 `2027H2-2028H1`，置信度中高/中。
- `高端电子玻纤布 + M7/M8/M9/M10 CCL/prepreg` 升为本周 PCB 材料链最强 `soft_bottleneck+`。AI PCB 专项 2026-06-14 已把高端电子玻纤布列为主深挖，台玻管理层称高端 Low DK/Low CTE 玻纤布供需吃紧预计至 2027 年底；Vexos 采购端也指向玻纤布、铜箔、树脂同步挤压 CCL。预计高端玻纤布 `2026H2-2027年底`，CCL `2026H2-2027H1`，Q cloth/NER 仍多为 watch；2026-06-16 08:48 邮件复核后，HVLP4/5 从纯 `watch` 上调为 `watch_to_soft / 高优先级验证`，但不进入当前核心卡点。
- `数据中心电力 / 并网 / transformer / switchgear / UPS / busway / rack power / CDU / 冷板 / 800VDC` 维持 `soft_bottleneck`，其中 PJM/Ohio/PA/Texas 等区域大负载并网按 `regional hard operational bottleneck`。Oracle Q4 FY26 的 $638B RPO、AI cloud buildout 融资和 $55.7B FY26 CapEx 强化需求侧，但全球设备单品 allocation/lead time 仍不够完整，不能把所有 power equipment 升为 hard。区域并网预计 `2026H2-2030`；全球设备/液冷/rack power 预计 `6-24 个月`，单品精确交期 `N/A`。
- `CoWoS / EFB / SoIC / advanced packaging / substrate` 维持 `soft_bottleneck/watch+`；`AI networking switch ASIC / NIC / DPU / retimer / custom XPU` 维持 `strategic_watch/watch_to_soft`。Broadcom、Marvell 与 Oracle 证明需求强，但本周仍缺 TSMC/OSAT/基板/silicon allocation、交期或客户排产延期的直接 A/B 证据。
- 本周进入全链横向排序的 5 个赛道：1）HBM/DRAM/NAND/eSSD + AI server parts；2）高端光源与 1.6T/3.2T 光互连；3）AI PCB/高端玻纤布/CCL/HVLP；4）数据中心电力/800VDC/rack power/液冷；5）advanced packaging + custom ASIC/networking silicon。
- 本期深挖 2 个方向：`memory/storage/server parts supply` 与 `AI cloud capex -> grid/power/rack power/liquid cooling`。光模块和 PCB 由专项覆盖，本报告只吸收结论并做横向排序。
- 本次已补录候选标的最新价格/收盘价、市值、PE/PB、换手率、涨跌幅；来源为本机 iFinD Finance Data MCP，妙想 mx-data 对台股 PE/PB 缺口补查未返回结构化数据，拿不到的字段继续写 `N/A`。行情只作为交易弹性和流动性背景，不改变本报告产业链判断。
- 2026-06-16 新增回主输出层的三条结论：`WF6/六氟化钨` 新增为半导体电子特气事件线，中船特气 `688146.SH` 可列 `main_candidate / 主受益候选`，但必须标注日本供应商“2026-07-01 永久停产”未获官方确认、公司新增订单和价格兑现未实锤；`ABF/IC载板 + AI server 高端 MLCC` 新增为 PCB/先进封装旁的次主线，深南电路偏基本面质量锚，兴森科技偏 ABF/FCBGA 订单突破期权，三环集团偏 MLCC 基本面主受益，风华高科偏高交易弹性；`800VDC/麦格米特` 只从普通观察升至 `watch+ / catalyst_watch`，生态入选不等同 NVIDIA/Google 直采。
- 2026-06-17 新增 HBM 施工扰动复核：韩国龙仁/平泽预拌混凝土运输罢工确曾造成三星平泽、SK 海力士龙仁施工浇筑中断，但 6 月 15 日二次暂定协议获通过、运输自 6 月 16 日恢复。该事项只进入 `watch / construction_delay_monitor`，不能进入项目主输出层；对雅克科技、有研新材这类 A 股 HBM 上游映射，不构成基本面强化，也不能写成直接订单利好。
- 2026-06-18 新增 NOR Flash / SLC NAND 窄口径复核：TrendForce 6 月 16 日把 NOR/SLC 结构性短缺归因于 HBM 与高层 3D NAND 产能优先级挤出、成熟节点退出、边缘 AI/汽车/工业/高端网络和 server boot/buffer 需求；兆易创新、东芯股份、普冉半导体 Q1 报告已经兑现存储涨价带来的收入、毛利和净利弹性。因此 603986.SH、688110.SH、688766.SH 从泛化“国产存储观察”上调到 `AI memory hierarchy / reliable small-capacity memory formal_observation`。但这仍是 memory hierarchy 侧翼观察层，不等同 HBM/LPDRAM/eSSD 主 `hard_bottleneck`，也不升 `main_candidate`。

## 2026-06-16 结论回主输出层

- NVIDIA/Google Q3 2026 小批量 800V HVDC 出货：目前公开可核验材料中，NVIDIA 官方能确认 800VDC 架构、生态伙伴和 2027 起支撑 MW 级机架方向；Google/OCP 硬资料更偏 `+/-400VDC` / Diablo 400 或 `+/-400/800V` 规范。TrendForce/商业时报的 Q3 小批量说法仍是供应链媒体口径，不能升为官方或一级来源。
- 麦格米特 002851.SZ：可确认的是 NVIDIA 800VDC 生态 `Power system components` 入选、公司年报/IR 披露的推荐提供商、产品体系、小批量送测/试产和部分北美项目线索；不能证明 NVIDIA 或 Google 直采订单。
- 结论层：Power/800VDC 节点维持 `soft_bottleneck/watch_to_soft`；麦格米特由普通 `watch` 调整为 `watch+ / catalyst_watch`，但不升 `main_candidate`。升级条件仍是官方/一级客户、订单金额、收入占比、毛利率和交付节奏兑现。
- WF6 / 六氟化钨：`中国钨出口许可 -> APT/钨粉供给与价格 -> WF6 成本和价格 -> 3D NAND/HBM/先进逻辑 CVD 钨沉积需求` 的传导方向成立，但不能把 Kanto Denka / Central Glass “2026-07-01 永久停产”写成硬结论。中船特气 `688146.SH` 具备直接 WF6 合成产能、6N 产品能力、客户覆盖和 2027 新增产能规划，列 `main_candidate / 主受益候选`；华特气体相关 WF6 合成产能叙事需排除误读，仅保留纯化/小占比观察。
- ABF / IC载板 与 MLCC：Ajinomoto 的硬证据是 ABF film 高集中材料节点，不是官方确认涨价；Ibiden 是海外 IC package substrate 扩产和 AI server 需求的 A 级硬锚。A 股直接映射分层为：深南电路 `002916.SZ` 是基本面质量锚，兴森科技 `002436.SZ` 是 FCBGA/ABF 订单突破期权。AI server 高端 MLCC 交期拉长和 Q4 缺货风险有 B+ 级证据，三环集团 `300408.SZ` 更接近基本面主受益，风华高科 `000636.SZ` 是高交易弹性标的，且“直供英伟达”不能写成事实。

- 结论层：不进入项目主输出层，不改写 HBM/DRAM/eSSD 的主 `hard_bottleneck`。它只作为 `watch / construction_delay_monitor`，跟踪是否复燃或造成实际工期顺延。
- A 股映射：雅克科技、有研新材的 HBM 材料逻辑必须回到各自产品、客户、订单、ASP、毛利和收入占比验证。本次施工扰动本身不证明材料订单增加；雅克科技最多 `event_trade_watch`，有研新材更偏 `theme_adjacent_watch / industry_noise`。
- 防误写规则：只有出现三星/SK 官方或承包商工期顺延、cleanroom handover 延后、tool move-in 延后、wafer-start/HBM ramp 调整，以及材料供应商订单/ASP/毛利兑现时，才能从 `watch` 上调；否则不得把“扩建延迟”写成“直接订单利好”。
