## 结论先行

1. 本周全链最硬约束仍是 `HBM / server DRAM / LPDRAM / NAND / enterprise SSD / AI server parts supply`。HPE 官方 10-Q 与 transcript、TrendForce enterprise SSD 价格和库存、Oracle RPO 与 Broadcom/Marvell AI 需求共同证明需求侧仍强，且 memory/storage 继续直接影响 AI server backlog 转收入。预计持续 `2026H2-2027H1`，若 HBM4E/HBM4、LPDRAM 与 eSSD qualification 慢于预期，可拖到 `2027H2`。
2. `HBM final/package test / memory probe card / Cube Prober` 从未来观察上调为 `watch_to_soft / soft_bottleneck_candidate`。The Elec 披露 Techwing 获 SK hynix Cube Prober 首单，和上期 MJC/探针卡线索方向一致，但合同规模、交期和内存厂官方瓶颈表述仍缺，不能独立升为 hard。
3. 光模块专项结论继续吸收为全链第二硬约束：`InP substrate / 6 英寸合格 InP / EML / CW-DFB / UHP pump / ELS` 维持 `hard_bottleneck`。本周不重复展开专项细节，只把它放入横向排序和未来迁移扫描。
4. AI PCB 专项本周没有把任何节点升为 hard，但 `高端电子玻纤布 / Low Dk / Low CTE / T-glass / NER-glass / Q cloth` 与 `M7/M8/M9/M10 CCL / prepreg` 维持 `soft_bottleneck+`。沪电股份 2026-06-18 投资者关系记录新增 A 级方向性证据：超低损耗树脂、HVLP 铜箔、特种高性能玻纤布存在阶段性供应偏紧。
5. 数据中心电力链从“主题热度”继续收敛成可跟踪的运营约束：FERC 2026-06-18 大负载并网规则行动是 A 级监管证据；Google Brazos 是 A 级存量风冷机房逐机架液冷改造线索；NVIDIA 800VDC 是 2027 起的架构迁移线索。当前结论仍是 `soft_bottleneck / regional hard operational bottleneck`，不是全球设备 hard。
6. 本周新增未来卡点观察：高端 MLCC/X6S、CoPoS/FOPLP/TGV、1.6T/3.2T 光电测试与热管理、M9/M10/Q cloth/HVLP4/5、800VDC-SST-GaN-SiC。它们更适合进入 6-24 个月迁移扫描，而不是当前主堵点。

## 深挖方向一：Memory/storage 与 HBM test/probe

### 约束机制

AI server 与 agentic inference 需求正在同时拉动 HBM、server DRAM、LPDRAM、NAND、enterprise SSD 和 AI server parts。约束不是单一价格周期，而是多个 qualified output 同时偏紧：

- HBM4E/HBM4 stack、base die、TSV、封装、测试与客户 certification 约束。
- DRAM wafer allocation 在 HBM、server DRAM、LPDRAM 之间再分配。
- Enterprise SSD 需要 controller、NAND、firmware、验证和 CSP qualification，不是通用 NAND 价格上涨就能立即缓解。
- HPE 的 backlog、purchase commitments 和库存变化说明 OEM/ODM 层正在把 memory/storage/parts 约束转化为现金流和营运资本压力。

### 持续时间判断

| 节点 | 预计持续时间 | 判断依据 | 置信度 | 缓解路径 | 反转指标 |
|---|---|---|---|---|---|
| HBM / DRAM / LPDRAM / NAND / eSSD | `2026H2-2027H1`；慢 ramp 可到 `2027H2` | HPE 官方 supply constraints 与 backlog；TrendForce eSSD 库存/价格；Oracle/Broadcom/Marvell 需求继续强。 | 中高 | HBM4E/HBM4 多供方认证、eSSD 扩产、LPDRAM allocation 放松、CSP LTA 节奏稳定。 | 内存厂不再提供不应求或 LTA；eSSD/DRAM/NAND 合约价回落；客户库存恢复；ODM 不再提 parts constraint。 |
| HBM test / memory probe card / Cube Prober | `2026H2-2027H2`；精确交期 `N/A` | Techwing 首单、MJC probe card 高需求、HBM stack 和 KGD 复杂度提升。 | 中 | Cube Prober/handler/probe card 扩产，多家供应商进入 memory maker AVL，测试节拍改善。 | 内存厂财报不再提 test/qualification 限制；供应商 backlog 回落；交期正常化；合同规模无法放大。 |

### 本周投资映射边界

- 主链受益更确定的是海外/韩国/日本/美国 memory、eSSD、HBM、test/probe 供应链。A 股只能从材料、测试、NOR/SLC 侧翼和交易弹性观察，不能把 NOR/SLC 直接写成 HBM 主受益。
- HBM test/probe 方向可以进入下周优先验证，但必须补合同金额、交期、内存厂官方 bottleneck、A 股公司订单或收入拆分。
- 雅克科技、精测电子、兆易创新、东芯股份、普冉半导体等只能按各自证据层级处理，不能用 memory 主 hard 自动提升为 main candidate。

## 深挖方向二：数据中心电力、并网、液冷与 800VDC

### 约束机制

数据中心从“有 GPU 订单”转成“可投产算力”需要同时满足 firm power、interconnection、许可、输配电、变压器、switchgear、UPS、busway、rack PDU、CDU、冷板、现场集成和运维服务。FERC 的大负载行动说明电网接入规则本身已成为公共议题；Oracle RPO 与 cloud CapEx 说明需求端仍未降温；Google Brazos 说明液冷需求池不只新建 AI factory，也开始覆盖部分存量风冷机房逐机架升级。

## 最大风险

1. 把价格上涨、毛利率提升、长认证周期或股票热度误判为堵点。堵点必须对应合格供给、可用产能、良率、交付能力或客户认证供应商不足。
2. 把专项任务结论重复扩写成全链主结论。光模块和 PCB 本期只吸收横向排序，不替代专项继续跟踪。
3. 把 FERC/Google/NVIDIA 的 A 级方向性证据直接写成 A 股订单。电力链和液冷链必须补客户项目、订单、预付款、收入占比和毛利。
4. 把 NOR/SLC 或 MLCC 侧翼主题拔高为 memory 主 hard。它们可以有交易弹性，但证据层级和产业约束位置不同。
5. 美股/海外大市值龙头的基本面强度和 A 股主题弹性不可混为一个总分。
