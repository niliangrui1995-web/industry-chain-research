## 方法与路由

- 路由：`industry-research-router -> ai-chain-research-orchestrator -> industry-chain-deep-disassembly -> semiconductor-ai-chain-investment-researcher`。
- 本周最佳实践口径：先用官方/监管/公司 IR 与财报做主证据，再用 TrendForce、DigiTimes、Reuters/CNA 等可信产业媒体补充价格、交期和节点线索；没有 `lead time / allocation / customer lock / order delay / qualified capacity gap` 的节点不升为当前 hard bottleneck。
- 适配器：本轮同时使用 optical-module、pcb-ccl、data-center-power、liquid-cooling 口径，避免把普通光纤、板级 PCB、ABF 载板、设施 UPS、服务器 PSU、机柜电源和液冷组件混在一起。

## 结论先行

1. 本周最明确的全链硬堵点仍是 `HBM / server DRAM / LPDRAM / NAND / enterprise SSD / AI server parts supply`。Micron FQ3 FY26 官方财报和 prepared remarks 把 DRAM/NAND tight、data center SSD 放量、HBM4 ramp、SCA/RPO/客户押金写成 A 级证据；该节点预计 `2026H2-2027全年` 偏紧，2028 只能写边际缓解观察。
2. `InP substrate / epiwafer / 6 英寸合格 InP / EML / CW-DFB / UHP pump / ELS` 继续作为光模块专项 hard bottleneck 进入全链第二层排序。本周 DigiTimes 线索强化 6 英寸 InP 和衬底约束，但主证据仍需 AXT/JX/Coherent/Lumentum/客户侧 A 级闭环。
3. AI PCB 专项本周未把任何节点升为 hard；`高端电子玻纤布 / Low Dk / Low CTE / T-glass / Q cloth` 与 `M7/M8/M9/M10 CCL / prepreg` 维持 `soft_bottleneck+`。树脂/化学材料交期线索增强，但 Reuters/CNA 更正后的 PPE/SABIC 断供叙事不能采用。
4. `数据中心并网 / 电力设备 / 液冷 / rack power / 800VDC` 维持 `soft_bottleneck`，其中并网/firm power 在部分区域是 `regional hard operational bottleneck`。FERC、Google Brazos、NVIDIA 800VDC/OCP 方向证据强化，但仍不能直接外推为 A 股订单。
5. 本周最值得深挖的 1-2 个方向：`memory/storage/LPDRAM/eSSD + HBM test/probe` 与 `data-center power/liquid/800VDC`。光模块和 PCB 已由专项覆盖，本报告只吸收结论并做横向排序。
6. 未来 6-24 个月潜在卡点迁移最值得盯：`HBM test/probe/Cube Prober`、`高端 MLCC/X6S/passives`、`1.6T/3.2T 光电芯片/FAU/测试/热管理`、`M9/M10/Q cloth/NER/HVLP4/5 与成品板良率/测试`、`CoPoS/FOPLP/glass core/TGV`、`AI networking ASIC/NIC/DPU/retimer/substrate`。
