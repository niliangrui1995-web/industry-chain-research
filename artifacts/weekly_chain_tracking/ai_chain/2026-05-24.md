# 周度总览：AI产业链上下游雷达

报告日期：2026-05-24  
覆盖窗口：2026-05-18 至 2026-05-24，北京时间  
任务目录：`artifacts/weekly_chain_tracking/ai_chain/`

## 结论先行

- 本周全链最硬约束仍是 `HBM / 高端 DRAM / enterprise SSD`，并把 `CoWoS / 2.5D advanced packaging` 从战略观察上调为 `soft_bottleneck/watch+`。NVIDIA FY2027 Q1 Data Center 收入继续上修，TrendForce 指向 AI server 出货增长，AMD 公开加大台湾先进封装生态投资，均说明 GPU/ASIC 需求正在把瓶颈压向 HBM、先进封装、基板和设备。
- `数据中心电力 / 并网 / 变压器 / switchgear / UPS / rack power / 液冷` 从 `soft_bottleneck/watch` 升级为 `soft_bottleneck`。DOE 对 PJM 的应急调度授权是本周最强新增 A 级证据，说明局部电网和可调度电力已出现运营性硬约束；但全球设备链仍缺逐项单品交期、allocation 或客户延期证据，不能整体升为 hard。
- `高端 EML / InP / CW laser / pump laser` 继续吸收光模块专项结论，维持 `hard_bottleneck`。本周 NVIDIA 与 Lumentum、Coherent、Corning 等先进光学链条合作信号强化需求端，但光源单品缺口仍交给光模块专项继续拆分。
- `M7/M8/M9 CCL / prepreg` 由 AI PCB 专项最新 2026-05-24 报告吸收，维持并强化为 `soft_bottleneck`；`高端电子布 / Low CTE / T-glass / Low Dk/Df` 维持 `soft_bottleneck+`；`HVLP/VLP/RTF PCB 铜箔` 升为 `soft_bottleneck/watch+`。
- 本周进入全链排序的 5 个赛道：1）HBM/高端 DRAM/eSSD；2）CoWoS/advanced packaging；3）高端 EML/InP/CW/pump laser；4）M7/M8/M9 CCL + 高端电子布/HVLP；5）数据中心电力/液冷/rack power。
- 本周 2 个深挖方向：`HBM/高端 DRAM/eSSD + CoWoS/2.5D`，以及 `数据中心电力/并网/液冷/rack power`。光模块和 AI PCB 已由专项覆盖，本报告只吸收结论并做横向排序。
- 最大证据缺口：HBM/CoWoS 的客户 allocation 明细、TSMC/OSAT 交期和排产；电力设备的变压器/switchgear/UPS/CDU/冷板单品 lead time；光源的 EML/CW/pump 缺口比例；PCB 材料的终端 AVL、交期和成交价。

## 本期深挖方向

1. `HBM / 高端 DRAM / enterprise SSD + CoWoS / 2.5D advanced packaging`
   - 目标：判断最硬约束是否从 HBM 单点扩展为 HBM + 先进封装 + eSSD/NAND + 封装设备组合约束。
   - 本期判断：HBM/高端 DRAM 仍为 `hard_bottleneck`；eSSD/NAND 为 `soft_bottleneck+`；CoWoS/2.5D 从 `strategic_watch` 升为 `soft_bottleneck/watch+`，但因缺 TSMC/OSAT 官方 allocation 或交期，暂不升 hard。

2. `数据中心电力 / 并网 / 变压器 / switchgear / UPS / rack power / 液冷`
   - 目标：把 AI capex 从芯片订单拆到电力可得性、并网、配电设备、rack power、液冷和工程交付。
   - 本期判断：全链升级为 `soft_bottleneck`；PJM/Mid-Atlantic 可标为区域性 `hard operational bottleneck`，但不把全球电力设备链整体写成 hard。

## 最大风险

- 把 GPU/ASIC 订单强直接误判为 GPU 成品短缺，忽略真正约束在 HBM、先进封装、电力、PCB 材料和光互连。
- CoWoS/advanced packaging 的本周新增证据虽强，但仍缺 TSMC/OSAT 官方交期和 allocation，不能写成全链 hard。
- 电力链局部 hard 和全球设备链 hard 不能混同。DOE/PJM 证明区域运营约束，不等于所有变压器、switchgear、UPS、CDU 都处于 allocation。
- PCB 材料链 A 股交易弹性已很强，但高端收入、客户 AVL、成交价和交期仍有缺口。
- 光源/InP 扩产若比预期快，allocation 解除后光源 hard 可能降级。
- AI capex 节奏如果被融资、监管、并网、客户 ROI 或电力成本压制，上游锁单可能转为库存风险。
