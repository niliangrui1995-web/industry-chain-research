# 周度总览：AI产业链上下游雷达

报告日期：2026-06-08
覆盖窗口：2026-06-01 至 2026-06-08，北京时间
任务目录：`artifacts/weekly_chain_tracking/ai_chain/`

## 结论先行

- 本期全链最硬卡点仍是 `HBM / server DRAM / NAND / enterprise SSD / AI server parts supply`。HPE、Broadcom、TrendForce、Micron/Samsung/NVIDIA 证据共同说明：AI server、custom ASIC、agentic inference 和 long-context memory hierarchy 正在把需求推到 memory、storage 和服务器 BOM。NVIDIA Vera Rubin 进入 full production、Samsung/NVIDIA HBM3E/HBM4 collaboration、Micron high-volume HBM4 路径强化了缓解路线，但不构成供给短缺解除。
- `高端 EML / InP / CW-DFB / pump / ELS / 1.6T 光互连组件` 维持当前 `hard_bottleneck`。本期不重复光模块专项细节，只吸收其 2026-06-07 状态：EML/InP/CW-DFB/pump/ELS 是 hard；整机装配 soft/eased；FAU/MT/主动对准/WLBI/热管理进入 future watch。
- `M7/M8/M9/M10 CCL / prepreg + 高端电子布` 维持 `soft_bottleneck+`。AI PCB 专项已更新至 2026-06-08，确认 CCL/prepreg 仍是当前最明确材料卡点，高端电子布为本期专项深挖卡点；HVLP4/5 因批量收入、客户和毛利证据不足，继续 watch。
- `数据中心电力 / 并网 / transformer / switchgear / UPS / busway / rack power / 800VDC / 液冷` 维持 `soft_bottleneck`，其中 PJM/Ohio/PA 类区域电力继续按 `regional hard operational bottleneck` 处理。全球设备链仍不升全局 hard，原因是单品 allocation、交期和订单纯度仍不完整。
- `CoWoS / EFB / SoIC / advanced packaging / substrate` 维持 `soft_bottleneck/watch+`；`AI networking switch ASIC / NIC / DPU / retimer / custom XPU` 维持 `strategic_watch/watch_to_soft`。需求很强，但本期仍缺 silicon、substrate、package 或客户排产延期的直接供给缺口证据。
- 本期进入全链横向排序的 5 个细分赛道：1）HBM/DRAM/NAND/eSSD + AI server parts；2）高端光源与 1.6T 光互连；3）AI PCB/CCL/高端电子布/HVLP；4）数据中心电力/800VDC/rack power/液冷；5）custom ASIC / AI networking silicon / advanced packaging。
- 本期深挖 2 个方向：`HBM/DRAM/NAND/eSSD + AI server parts supply` 与 `数据中心电力/并网 + 800VDC/SST/rack power/液冷`。光模块和 PCB 由专项覆盖，本报告只吸收结论并做横向排序。
- 本期未逐项刷新 A/H/台/美股最新价格、市值、PE/PB、换手率；涉及交易弹性只做定性排序，行情字段写 `N/A`。
