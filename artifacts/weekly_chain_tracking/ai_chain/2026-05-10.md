# AI产业链上下游雷达周度总览

报告日期：2026-05-10  
覆盖窗口：2026-05-07 至 2026-05-10（北京时间）  
任务目录：`artifacts/weekly_chain_tracking/ai_chain/`

## 结论先行

- 本期最明确的全链堵点仍是三条：`HBM/AI memory`、光模块上游 `高速 EML / InP / CW laser`、AI PCB 上游 `M7/M8/M9 CCL/prepreg`。其中 HBM 与高速光源链仍按 `hard_bottleneck` 处理，CCL/prepreg 按 `soft_bottleneck` 处理。
- 本期加剧或被进一步确认的方向：高速光模块上游最强。Lumentum 与 Coherent 的 2026-05-05/06 官方结果和演示材料继续显示 EML、CW laser、InP、1.6T、CPO/OCS 的需求与产能扩张压力。Corning 与 NVIDIA 的长期合作把“光连接/光纤/高密互连”推入未来迁移池。
- 本期新增进入全链排序的方向：`CoreWeave/AI cloud + 数据中心电力/液冷/rack power`。CoreWeave 的收入、backlog、capex 与合同电力增长，叠加 Eaton、Schneider 的数据中心需求和 backlog，说明电力与液冷不是纯主题，已进入 `soft_bottleneck/watch`。
- 本期缓解项：光模块整机“部分关键物料同步”仍由专项任务判断为 `easing_watch`，不能继续泛化成所有物料硬缺；AI PCB 成品板厂仍是需求和高利用率确认，未升为加工产能硬瓶颈。
- 本期被证伪或降级项：DSP/TIA/CDR、普通服务器 ODM、泛树脂、普通电子布、普通液冷部件仍不能按当前堵点处理；CoWoS/advanced packaging 结构重要性很高，但本周新增证据仍不足以从 `strategic_watch` 升级为当前硬堵点。
- 本期最值得深挖的 2 个方向：`HBM/AI memory` 与 `数据中心电力/液冷/预制化基础设施`。光模块和 PCB 专项已有报告，本期只吸收结论并做横向排序。

## 最大风险

- 把“结构重要”“高壁垒”“高 HHI”“高毛利”误判为堵点。当前只有 HBM、高速光源链、CCL/prepreg、数据中心电力/液冷部分节点满足供需缺口或交付约束的证据门槛。
- AI capex 订单提前拉货、库存周期或融资压力放大，导致上游价格先涨后落。
- HBM、InP/EML、CCL/T-glass、电力设备的新产能和二供认证快于预期，堵点持续时间缩短。
- A 股光模块、PCB 材料、电力设备交易过热，股价弹性领先业绩兑现。
- 光模块和 PCB 专项中的 C 级线索不能直接升为全链主结论；必须等官方 transcript、10-Q、IR 原文、成交价或交期数据。
