# 周度总览：AI产业链上下游雷达

报告日期：2026-05-31  
覆盖窗口：2026-05-24 至 2026-05-31，北京时间  
任务目录：`artifacts/weekly_chain_tracking/ai_chain/`

## 结论先行

- 本周全链最硬约束继续落在 `HBM / 高端 DRAM / enterprise SSD / AI server parts supply`，并由 Dell Q1 FY27 官方财报和业绩会进一步强化为 `hard_bottleneck`。Dell 同时给出 AI 订单、AI server 收入、AI backlog、需求超过供应、memory/parts supply 约束，是本周最强 A 级供需缺口证据。
- `高端 EML / InP / CW / pump / ELS` 继续吸收光模块专项，维持 `hard_bottleneck`。Coherent 6 英寸 InP 良率/产量路径官方化，Semtech 1.6T 光互连需求和 backlog 增强，说明卡点正在从传统模块整机向高端光源、光互连组件、测试/主动对准迁移。
- `M7/M8/M9 CCL / prepreg + 高端电子布 / Low CTE / T-glass + HVLP` 吸收 AI PCB 专项，维持 `soft_bottleneck` 到 `soft_bottleneck+`。高端电子布偏紧进一步增强，但仍缺分产品交期、配额和核心客户 AVL。
- `数据中心电力 / 并网 / transformer / switchgear / UPS / rack power / 液冷` 维持 `soft_bottleneck`，其中 PJM/Ohio/PA 区域电力与并网可按 `regional hard operational bottleneck` 处理。全链不把 transformer、switchgear、UPS、CDU 全部升 hard，因为本周仍缺单品 lead time、allocation 和交付延期的 A 级证据。
- `CoWoS / SoIC / EFB / advanced packaging / advanced substrate` 维持 `soft_bottleneck/watch+`，不升 hard。本周新增证据更多是 AMD/Marvell/NVIDIA 需求和锁产能逻辑，仍缺 TSMC/OSAT 官方交期、allocation、良率或客户排产延期。
- 本周进入全链排序的 5 个赛道：1）HBM/DRAM/NAND/eSSD 与 AI server parts supply；2）高端光源与 1.6T/3.2T 光互连；3）AI PCB/CCL/高端电子布/HVLP；4）数据中心电力/并网/rack power/液冷；5）CoWoS/EFB/advanced packaging 与网络 silicon。
- 本周深挖 2 个方向：`HBM/DRAM/NAND/eSSD + AI server parts supply`，以及 `数据中心电力/并网 + 800VDC/SST/rack power/液冷`。光模块和 AI PCB 已由专项覆盖，本报告只吸收结论并做横向排序。
- 本期未逐项刷新 A/H/台/美股最新价格、市值、PE/PB、换手率；涉及交易弹性时只做定性排序，行情字段写 `N/A`，不使用记忆补数。

## 最大风险

- 把 Dell AI server 交付受限误读为 ODM 装配产能不足。Dell 的表述更准确地指向 parts supply，尤其 memory、microprocessors、NAND/DRAM/HDD/PCB 等组合。
- Samsung HBM4E 送样是未来缓解路径，不等于当前 HBM4E 合格量产供给已释放；不能因此把 memory hard 降级。
- Marvell/NVIDIA/AMD 的 custom ASIC、NVLink Fusion、advanced packaging 证据强，但大多证明需求和生态，并未直接证明交期/allocation。
- 电力链区域 hard 与全球设备链 hard 不能混同。本周可以把 PJM/Ohio/PA 作为区域硬运行约束，但 transformer/switchgear/UPS/CDU 仍需单品 lead time。
- PCB 和光模块专项均显示 A 股交易弹性很强，但高端收入占比、客户 AVL、成交价和交期仍是主要缺口。
