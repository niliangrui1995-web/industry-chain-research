# HVLP4 铜箔 / T-glass 玻纤布证据分层

报告日期：2026-06-17

## 结论先行

- 这条线足以把 `artifacts/weekly_chain_tracking/ai_chain/2026-06-14.md` 里 `HVLP4/5` 从纯 `watch` 上调为 `watch_to_soft / 高优先级验证`，但不足以升为当前 `soft_bottleneck+` 或 `hard_bottleneck`。理由是高端 HVLP 需求和扩产压力已有 A/B 级证据，但 `NVIDIA 直签`、`寄售`、`提前一年锁产能` 尚未见 NVIDIA、Nittobo、Mitsui、Co-Tech 或 A 股公司的正式公告、法说问答、LTA、capacity reservation 或 consignment 合同证明。
- `高端电子玻纤布 / Low Dk / Low CTE / T-glass / NER-glass / Q cloth` 仍维持 `soft_bottleneck+`。这里的上调依据来自 Nittobo/Taiwan Glass/TrendForce 等对高端布种供给紧、扩产慢和二供验证慢的证据；邮件只强化验证优先级，不新增 A 级闭环。
- 邮件中的海外材料股大涨、X/Grok 多源、P4 行情验证只能证明资金正在定价该叙事，不能证明直签、寄售、锁量或实际 allocation。
- 公司分层：生益科技放 `基本面主受益 / 质量锚`；宏和科技放 `交易弹性 / 高优先观察`；德福科技放 `交易弹性 / 条件式 HVLP 期权`；中英科技放 `仅观察 / PTFE-M10 相邻线索`。

## 载板 T-glass 与板级 PCB/CCL 电子布分开记录

| 维度 | 载板用 T-glass / Q glass / Low CTE | 板级 PCB/CCL 用 Low Dk / Low Df / Low CTE 电子布 |
|---|---|---|
| 链条位置 | ABF/BT/FC-BGA/IC package substrate，属于封装载板链 | AI server、switch、backplane、networking board 的 CCL/prepreg 增强材料链 |
| 核心功能 | 控制封装基板翘曲、CTE 匹配、热循环可靠性，和 ABF film、stepper、载板良率共同约束 | 控制高速信号损耗、Dk/Df、skew、CTE、CAF 和层压可靠性，和树脂、HVLP 铜箔、CCL 配方共同约束 |
| 直接客户 | 载板厂、封装生态、OSAT/IDM/芯片客户 | 电子布厂 -> CCL 厂 -> PCB 厂 -> AI server/switch 客户 |
| 证据看什么 | FC-BGA/ABF 载板 UTR、advance payment、capacity reservation、stepper 排队、载板良率、ABF/BT 收入 | M8/M9/M10 CCL lead time、报价、AVL、二供认证、CCL/PCB 订单延期、高端布分布种收入 |
| A 股映射 | 兴森科技、深南电路只能按 FC-BGA/BT/IC 载板证据单独验证 | 生益科技、南亚新材、宏和科技、国际复材、中材科技、德福科技等按 CCL/电子布/HVLP 分层验证 |
| 禁止外推 | 载板 T-glass 偏紧不能自动推导板级 CCL 已缺货 | 板级 Low Dk/Low CTE 电子布涨价不能自动推导 ABF 载板锁产 |

执行规则：后续所有记录增加 `end_use` 字段，至少区分 `IC substrate / package substrate`、`board-level CCL`、`finished PCB`、`PCB copper foil`。同一个供应商、同一个“T-glass”词，不得跨用途自动升级。

## 2026-06-17 官方证据追杀补充

补充报告：`artifacts/weekly_chain_tracking/ai_pcb/2026-06-17_hvlp_tglass_nvidia_official_lock_capacity_chase.md`

本轮只看 NVIDIA、Nittobo、Mitsui、Co-Tech 官方/IR/年报/SEC 文件和 DIGITIMES 一级媒体原文后，`NVIDIA 直签寄售锁 HVLP4 铜箔 / T-glass 玻纤布产能` 总判定维持 `仍未闭环`：

- `直签 / direct approach`：DIGITIMES 可作为 B 级线索，表述是 NVIDIA 接洽 Co-Tech 讨论长期产能规划，不是已签合同。
- `寄售 / consignment`：未找到相关可用证据；Nittobo PDF 中 `consignment` 为诊断试剂业务无关命中。
- `capacity reservation / LTA / prepayment`：NVIDIA 10-Q 有公司层面的通用供应链预付和产能协议披露，但未指向 Nittobo、Mitsui、Co-Tech、T-glass、HVLP 或 PCB 铜箔。
- Co-Tech 年报、Mitsui 法说和 Nittobo 年报均强化了 HVLP4/T-glass 供需偏紧、扩产慢、客户催产能，但不支持把这条线写成 NVIDIA 已锁产。
