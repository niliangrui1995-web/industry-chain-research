## 任务边界

本任务只跟踪板级 AI PCB 及其上游材料、设备和耗材：

- AI 服务器/交换机板级 PCB
- 高速 CCL / prepreg
- 低 Dk / 低 Df / 低 CTE 电子布、T-glass、石英布、超薄布
- HVLP / VLP / RTF 铜箔
- PPO / PPE / 碳氢 / 活性酯 / BMI 等高频高速树脂体系
- 钻针、压合、曝光、钻孔、电镀、测试设备
- 湿化学、油墨和其他 PCB 工艺材料
- ABF / BT 封装载板只能单独列示，不得与板级 PCB 混同
