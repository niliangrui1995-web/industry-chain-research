# 周度跟踪：AI PCB及上游材料设备 - 滚动状态

## 任务边界

本任务跟踪板级 AI PCB 及其上游材料、设备和耗材。必须区分：

- AI 服务器/交换机板级 PCB。
- 高速 CCL / prepreg。
- 低 Dk / 低 Df / 低 CTE 电子布、T-glass、石英布、超薄布。
- HVLP / VLP / RTF 铜箔。
- PPO / PPE / 碳氢 / 活性酯 / BMI 等树脂体系。
- 钻针、压合、曝光、钻孔、电镀、测试设备。
- 湿化学、油墨和其他 PCB 工艺材料。
- ABF / BT 封装载板只能单独列示，不得与板级 PCB 混同。

## 首次运行要求

首次执行时，请使用 `BASELINE_TEMPLATE.md` 建立第一期报告，并完成：

1. 先建节点全景，再判断堵点，不从股票名称倒推。
2. 按成品板、CCL/prepreg、电子布/玻纤、铜箔、树脂、设备/耗材/化学品分层。
3. 对每个节点判断是 `hard_bottleneck / soft_bottleneck / watch / rejected`。
4. 把 ABF/BT 与板级 AI PCB 分开评估。

## 候选观察池

以下只是首期需要检查的候选节点，不是当前结论：

| 候选节点 | 需要验证的堵点问题 | 不可直接下结论的原因 |
|---|---|---|
| 高速 CCL / prepreg | 是否出现高频高速材料涨价、分配、认证排队或合格供给不足 | 不能把普通 CCL 涨价直接等同于 AI PCB 材料堵点 |
| 高端电子布 / T-glass / 石英布 | 是否是低 Dk、低 Df、低 CTE 材料供给瓶颈 | 低端电子布或普通玻纤产能不能替代高端布 |
| HVLP / VLP / RTF 铜箔 | 是否存在高端低粗糙度铜箔供给、认证或交付压力 | 电池铜箔产能不能证明 PCB 铜箔供给充足 |
| 高频高速树脂体系 | 是否有 PPO/PPE/碳氢/活性酯/BMI 等配方和认证瓶颈 | 不能把泛树脂公司直接当作高端 PCB 树脂受益者 |
| 高层高速 PCB 制造 | 是否有高层数、钻孔、压合、良率、测试和客户审核限制 | 普通 PCB 产能不能证明 AI 服务器/交换机板供给充足 |
| 钻针/设备/湿化学 | 是否因高层高速板工艺升级带来设备、耗材或化学品瓶颈 | 需要证明对 AI PCB 制程有直接限制 |
| ABF / BT 封装载板 | 是否存在独立封装载板供需缺口 | 这不是板级 AI PCB，必须单独评估 |
