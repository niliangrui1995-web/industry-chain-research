# HVLP4 / T-glass NVIDIA 锁产能官方证据追杀

日期：2026-06-17
追杀范围：NVIDIA、Nittobo、Mitsui、Co-Tech 的官方公告、法说、IR、年报/SEC 文件，以及必要的一级媒体原文。
核对表述：`直签`、`寄售/consignment`、`capacity reservation`、`LTA`、`prepayment/prepaid/deposit`、`提前锁产能`。

## 结论先行

- “NVIDIA 直签寄售锁 HVLP4 铜箔 / T-glass 玻纤布产能”总判定：`仍未闭环`。本轮没有找到 NVIDIA、Nittobo、Mitsui 或 Co-Tech 把相关材料、供应商、客户和合同条款连在一起的 A 级证据。
- `直签 / direct approach`：只能保留为 DIGITIMES 的 B 级供应链线索。DIGITIMES 可见原文说 NVIDIA 直接接洽 Co-Tech 讨论高端 HVLP4 铜箔长期产能规划，但这不是已签采购、寄售、预付款或 capacity reservation。
- `寄售 / consignment`：在本轮源集内不能采用。Nittobo PDF 里出现的 `consignment` 是体外诊断试剂业务的抗体生产委托，和 T-glass/HVLP 无关；NVIDIA、Mitsui、Co-Tech 相关材料未命中可用表述。
- `capacity reservation / LTA / prepayment`：NVIDIA 最新 10-Q 有通用的供应链预付款、长期供应和产能承诺风险披露，但没有点名 Nittobo、Mitsui、Co-Tech、T-glass、HVLP 或 PCB 铜箔；不能外推为这条链已锁产。
- 对节点口径的影响：`HVLP4/HVLP5 PCB 铜箔` 维持 `watch_to_soft / 高优先级验证`，不升 `soft_bottleneck+`；`高端电子玻纤布 / T-glass / NER-glass / Q cloth` 维持 `soft_bottleneck+`，但依据仍是供需偏紧和扩产慢，不是 NVIDIA 锁产合同。

## 更新后的执行规则

- 后续提到这条线时，只能写：`NVIDIA 接洽 Co-Tech 讨论长期产能规划的 B 级线索 + 官方材料确认 HVLP4/T-glass 供需偏紧`。
- 禁止写：`NVIDIA 已直签`、`寄售锁产`、`提前一年锁产能`、`已做 capacity reservation`、`已签 LTA`，除非后续出现 NVIDIA/供应商/客户官方公告、SEC/交易所文件、法说问答或可核验合同摘要。
- 触发上调到 `可上调一档` 的最小证据：至少一条 A 级来源把 `客户/供应商`、`材料/规格`、`合同或产能保留条款` 三者同框；或两条以上独立 A/B 来源披露相同的客户指定、预付款/产能保留、交期/配额和量化产能。
