# 周度跟踪：AI PCB 及上游材料设备

报告日期：2026-06-08  
覆盖窗口：2026-06-07 至 2026-06-08，北京时间  
任务目录：`artifacts/weekly_chain_tracking/ai_pcb/`

## 结论先行

- 本轮为上次 2026-06-07 报告后的增量复核；没有发现足以把任何节点升级为 `hard_bottleneck` 的 A/B 级新证据。
- 当前最明确供需矛盾仍是 `M7/M8/M9/M10 CCL / prepreg`，维持 `soft_bottleneck`，状态为 `unchanged_to_worsened`。理由是需求、涨价、采购端交期压力和部分供应商满载证据继续增强，但官方分产品 allocation、订单延期、客户 AVL 排队和 qualified output 缺口仍不完整。
- 本期主深挖环节切换为 `高端电子布 / Low Dk / Low CTE / T-glass / Q cloth / 石英布`。选择原因是该节点更可能成为 CCL 之后的卡点迁移方向，且本轮新增行业资料继续指向电子布价格、原纱、织布和高端布种有效供给约束。
- `HVLP/VLP/RTF PCB 铜箔` 维持 `watch_to_soft`，不按 hard 处理。诺德股份 IR 仍是关键反证：HVLP1/2/3 有百吨级订单，但 HVLP4 仍在客户测试，HVLP5 尚在开发。
- `成品 AI PCB 高层板良率/测试/交付` 仍是 `watch`。5 月营收和高阶产品 mix 继续证明订单兑现，但不等于交期、良率、测试能力或客户转单卡点已经被证实。
- 未来 6-24 个月最可能的新卡点或迁移方向：`M9/M10 CCL + 高端电子布/Q cloth`、`高层高速板良率/阻抗测试`、`HVLP4/HVLP5 PCB 铜箔`、`钻针/测试设备/湿化学/PCB 光刻胶`。
- 最大证据缺口：官方分产品 lead time、allocation、客户认证排队、订单延期、可用合格产能与实际需求缺口；订阅墙标题、研报摘要、采购端博客和股价热度只能提高观察优先级，不能单独支撑 hard 结论。

## 本期主深挖环节：高端电子布 / Low Dk / Low CTE / T-glass / Q cloth

| 问题 | 本期判断 |
|---|---|
| 精确短缺对象 | 用于 AI server/switch 高速 CCL 和高层高速 PCB 的 Low Dk、低 Df、Low CTE、T-glass、Q cloth/石英布、超薄高端电子布；不是普通电子布、建筑/风电玻纤或通用纺织玻纤布。 |
| 为什么相邻供给不能解决 | 普通布和普通玻纤不能满足高速低损耗材料的介电损耗、热膨胀、厚度一致性、层压可靠性和客户 AVL 要求；低端织机或工业纱改造只能补普通布，不等于高端布有效合格供给。 |
| 需求触发 | M7/M8 已成为 AI server/switch 主流材料压力，M9/M10、Rubin、112G+/224G+、1.6T/3.2T 和正交背板/Q cloth 路线会把约束向更高端布种迁移。 |
| 供应约束机制 | 窑炉/拉丝、电子级原纱、织布机、后处理、良率、厚度和介电一致性、客户认证和 AVL；新增产能必须从物理产能转为客户合格产能。 |
| 当前供需缺口证据 | 上期 A 级证据来自中材科技“特种纤维布供不应求”和沪电点名特种高性能玻纤布偏紧；本期 B/C 资料继续提示电子布、原纱、二代 Low-Dk/Q cloth 方向紧张。 |
| 严重程度 | `soft_bottleneck`，本期状态 `unchanged_to_worsened`。仍不升 hard，因为缺分产品官方交期、配额、断供、客户 AVL 排队数量或订单延期。 |
| 预计持续时间 | 2026H2-2027H1：中高置信偏紧；Q cloth/石英布：2027H2-2028 watch。若 2026 年底前新增产能不能转为 qualified output，则 2027H1 仍可能维持软卡点。 |
| 置信度 | 中高。需求和供应刚性逻辑强，A/B 证据可支持软卡点；但 hard 证据不足。 |
| 缓解路径 | Nittobo、台玻、宏和、中材、国际复材等新增高端布种产能爬坡并进入核心客户 AVL；CCL/板厂二供认证放开；高端布库存恢复。 |
| 反转指标 | 高端布报价停止上涨或回落，原纱/织布库存恢复，客户不再“有什么布买什么布”，多家供应商进入核心 CCL/板厂 AVL，M9/M10/Q cloth 需求推迟。 |

- 把 CCL/PCB 月营收创新高直接等同于 `hard_bottleneck`，忽略交期、allocation、订单延期和 qualified capacity 证据缺口。
