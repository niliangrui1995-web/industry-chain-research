## 结论先行

- 本周最明确堵点：`InP substrate / epiwafer / 6 英寸合格 InP 平台 / EML / CW-DFB / UHP pump / ELS` 继续是当前主硬堵点。新增 B 级证据显示 InP 出口缓解不足、6 英寸 InP wafer 遇到供给墙、IntelliEPI 等外延厂仍受 InP substrate 短缺约束；这强化“短期合格供给不足”，但没有改变 A 级缓解路径仍需 Coherent/JX/IQE/Tower/Lumentum/AXT 后续兑现的判断。
- 本周加剧的堵点：严格说没有 A 级证据证明堵点突然恶化；但 InP 相关 B 级证据增强，主堵点状态记为 `unchanged / evidence_strengthened`。
- 本周缓解的堵点：无新增 A/B 证据证明 EML/InP/CW/ELS 已缓解。光模块整机装配与关键原材料同步继续维持 `soft_bottleneck/eased`，本窗口没有中际、新易盛、天孚、光迅、东山等披露新的交付受限、关键物料短缺、客户认证失败或订单延期。
- 本周新增观察卡点：光库科技并购安捷讯修订稿把 `光无源器件 / FAU / MT / MPO / Receptacle / Lens / 高速光互联组件` 的 A 股映射增强；但这是产品布局和并购协同证据，不是交期、涨价、良率或客户排队证据，仍不能升级为当前 hard bottleneck。
- 本周被证伪或降级的卡点：源杰科技、云南锗业、长飞光纤的官方风险/异动公告均强化交易热度高于业绩兑现的边界；罗博特科新增 H 股备案只是资本路径进展，不是 ficonTEC/CPO 设备订单或验收收入。
- 当前堵点预计持续时间/缓解窗口：EML/InP 偏紧仍预计 `2026H2-2027H1`，置信度中高；CW-DFB/UHP/ELS 与 CPO/NPO/scale-up 光互连相关尾部可能延至 `2027H2-2028H1`，置信度中；JX/Coherent/Lumentum/非中国 InP 产能若完成客户认证，`2028-2030` 起长期缓解概率上升。
- 未来最可能出现卡点的其他环节：`CPO/NPO 光引擎与 ELS package`、`FAU/fiber array/MT/MPO/微透镜/高密连接`、`主动对准/WLBI/OWAT/光电联合测试`、`模块/光引擎热管理与液冷兼容`。
- 最大证据缺口：缺 A 级单品交期、allocation、价格、客户锁产能金额、6 英寸 InP 良率/认证节点、EML/CW/ELS 收入拆分、A 股公司订单/收入/毛利拆分，以及 CPO 设备链订单、交付、验收收入。

## 本期主深挖与次级跟踪

- 主深挖：`InP substrate / epiwafer / 6 英寸合格 InP 平台` 对 EML、CW-DFB、UHP pump、ELS 和 CPO/SiPh 外置光源的约束。

## 最大风险

- 下游 AI capex、CPO/ELS 或 1.6T/3.2T 升级节奏低于预期，导致光源和光连接去库存。
- Coherent、JX、Lumentum、IQE/Tower 等扩产比预期更快通过认证，InP/EML 硬堵点提前缓解。
- InP 出口许可和非中国供给改善，使材料短缺叙事快速降温。
- A 股源杰、云南、长飞等交易热度显著领先经营兑现，官方风险公告已提示估值和价格波动风险。

- 把并购、H 股备案、可转债发行、产品定义扩充误写成客户订单、产能排队或毛利兑现。
