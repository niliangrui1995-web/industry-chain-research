## 结论先行

茂莱光学可以补入 `EUV 光学元件 / ASML 配套` 的最小跟踪池，但当前硬证据只能定位到 `ASML/EUV scanner 需求扩张下的半导体设备精密光学配套观察`，不能写成已确认 ASML/SK hynix 订单、EUV scanner 指定部件收入或毛利兑现。

可确认的是：SK hynix DART 披露确认向 ASML Korea 采购 `EUV(Extreme Ultraviolet) Scanner`，合同金额披露为 `€6,913.4 million / KRW 11,949,673,632,000`，预计取得日至 2027-12-31；SK hynix DR/ADR 披露确认 Nasdaq Global Select Market 上市安排、参考募集总额 `KRW 45,453,450,000,000`，且资金用途包括 Yongin 半导体集群一期 fab、Cheongju P&T7 Advanced Packaging fab 及 EUV scanner 相关设施投资；ASML 官方确认 EUV lithography systems 用于先进 Logic 和 Memory 芯片量产；茂莱光学 2026Q1 报告和投资者关系记录确认半导体量检测客户订单/收入增长，但同时披露低毛利客户业务占比提升导致毛利率和净利润承压。

邮件里的交易映射只作为 `C/lead`：`SK hynix ADR 融资 + ASML EUV 采购 -> 茂莱光学/福晶科技` 可以提出待核问题，但不能直接升级为茂莱光学 ASML 供货、SK hynix 订单、收入占比、毛利率或股价弹性的硬证据。福晶科技仅保留为邮件中的长期 EUV 光源晶体材料线索，本次不扩写公司卡。

## 交易映射边界

1. `SK hynix capex -> ASML EUV scanner` 是 A 级需求侧证据；`ASML scanner ecosystem -> 茂莱光学订单` 仍缺公司、客户或供应商直接披露。
2. 茂莱硬证据更接近 `半导体量检测/半导体设备精密光学配套`，不能把它直接写成 ASML EUV 核心光学系统供应商。
3. 邮件中的 `79.7 亿美元` 应视为美元换算/交易口径；DART 原文硬口径为 `€6,913.4 million / KRW 11,949,673,632,000`。
4. 邮件中的 `Q1 半导体订单 4.55 亿元，同比 +82%` 应写为 IR 披露的 `在手订单约 6.6 亿元、约 69% 来自半导体、同比约 +82%` 的折算值。
5. 邮件中的 `ASML 2027 年交付 90 台 EUV` 本次未核到 ASML 官方同口径确认，暂不写入硬证据。

## 最大风险

- 把 SK hynix 对 ASML 的 EUV scanner 采购直接等同于茂莱光学订单。
- 把半导体在手订单增长直接等同于利润兑现；公司 Q1 已披露低毛利客户业务占比提升和净亏损。
- 客户保密、供应链资格、出口管制或 ASML/ZEISS 核心光学系统边界导致茂莱实际可触达价值量低于市场映射。
- 福晶科技和茂莱光学不在同一细分节点，本次不做横向收益排序。

## 后续跟踪指标

1. 公司公告/IR 是否直接披露 ASML、ASML Korea、SK hynix、EUV、光刻机部件或半导体设备客户名称。
2. 半导体在手订单、国际半导体量检测客户订单、交付进度、收入占比、毛利率和前五大客户变化。
3. SK hynix DR/ADR 定价和募集资金用途修正披露，以及 EUV scanner 采购交付节奏。
4. ASML 季报/年报中的 EUV backlog、shipments、capacity 和 High-NA/EUV memory demand 表述。
5. 应收账款、存货、合同负债、经营现金流能否支持订单向收入和利润转化。
