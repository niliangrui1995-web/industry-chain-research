# 雅克科技（002409.SZ）公司最小基线

建立日期：2026-06-18
来源层级：公司年报 / 一季报 / 投资者关系活动记录 / 异动公告 / 监管反馈；邮件和 open-web 只作线索层。

## 一、上市主体与业务定位

雅克科技是深交所主板上市的新材料平台公司。当前跟踪只围绕电子材料中的 `UP Chemical / 江苏先科 / 半导体前驱体 / SOD`，并把它放在 HBM 主链的材料侧观察层，不把公司泛化为“HBM 概念股”。

公司 2025 年报披露，主营业务包括 LNG 保温绝热板材、半导体前驱体材料、光刻胶、半导体封装填充料及电子粉体材料、特种气体、电子湿化学品和 LDS 等。电子材料产品线丰富，但本 baseline 不把所有电子材料都并入 HBM 逻辑。

## 二、窄口径 HBM 材料主线

| 字段 | 当前答案 |
|---|---|
| taxonomy path | `AI 数据中心 / 智算中心 > GPU/ASIC 加速计算链 > HBM / 高带宽近端内存 > HBM DRAM/stack process materials（前驱体/SOD 为材料 P5 线索）` |
| 核心产品 / 服务 | 半导体前驱体材料、SOD；公司披露前驱体包括 high-k、硅基、金属材料等类别。 |
| 下游应用 | DRAM/HBM、3D NAND、NOR Flash、逻辑芯片先进制程，以及 AI 先进封装复杂芯片组相关薄膜沉积材料需求。 |
| 终端需求驱动 | AI 训练/推理算力、HBM4E/HBM4 与存储厂扩产、先进封装复杂芯片组材料需求。 |
| 公司证明 | 2026-05-19 业绩说明会称 HBM 前驱体一直有供应，随着国内和海外 FAB 厂 HBM 产能增长，前驱体材料需求持续增长；并称在客户 HBM 已有稳定供应产品。 |
| 传导路径 | HBM/DRAM fab 产能提升 -> 工艺材料用量增加 -> UP Chemical/江苏先科前驱体/SOD 供应 -> 雅克电子材料收入、产品结构和毛利。 |
| 当前分层 | `event_trade_watch / baseline_worthy`。可跟踪，但不升 `main_candidate`。 |
