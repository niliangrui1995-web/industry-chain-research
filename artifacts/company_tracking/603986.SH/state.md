## 当前结论

兆易创新本次从泛化“国产存储观察”上调为 `AI memory hierarchy / reliable small-capacity memory formal_observation`，公司层分层为 `formal_observation / quality_anchor`。

对应节点是 `NOR Flash + MCU / 高可靠小容量存储`。本次 durable 化的重点不是把公司升为 HBM、LPDRAM 或 eSSD 主线，而是确认：在 HBM 和高层 3D NAND 抢占产能优先级、小容量成熟制程供给退出、边缘 AI/汽车/工业/高端网络及 server boot/buffer 需求共振的背景下，NOR/SLC 价格和盈利兑现已经足以进入正式观察层。

## 为什么不升主线

- 该节点受益于 AI memory hierarchy 的侧翼需求与成熟节点供给挤出，但不直接约束 AI server、long-context inference、agentic workload 或云厂商 backlog 转收入。
- 当前缺 AI server/eSSD 级客户 LTA、容量认证、产品结构、AI 侧收入占比和直接订单证据。
- 不能把 NOR Flash 涨价直接等同 HBM/LPDRAM/eSSD `hard_bottleneck`，也不能把存储涨价标签直接写成主受益候选。

## 三层分级

| 层级 | 当前判断 | 依据与边界 |
|---|---|---|
| 基本面质量 | 中高 / quality_anchor | NOR/MCU 龙头属性更清晰，Q1 报告确认存储芯片供不应求、量价齐升和盈利能力提升。 |
| 业绩弹性 | 高 | 2026Q1 归母净利 14.61 亿元，同比 +522.79%，毛利率修复明显；后续要看 H1/H2 ASP 与毛利持续性。 |
| 交易弹性 | 中高 | 存储涨价与国产龙头标签较强，但已不能只按 theme 交易；需另行核对估值、拥挤度和趋势位置。 |

## 后续必须跟

1. NOR 分产品 ASP、毛利率、库存天数和现金流是否在 2026H1/H2 延续改善。
2. 高密度 NOR、车规/工业/高端网络/server boot 或 buffer 相关客户结构是否披露。
3. 是否出现 LTA、选择性接单、客户预付款、长单锁量或交期拉长证据。
4. AI server 直接收入、eSSD 级客户、数据中心客户认证或容量认证证据目前为 `N/A`，有披露才允许上修。
5. 若低密度产能释放、补库结束、报价回落或毛利率回落，降回 `theme_adjacent/watch`。
