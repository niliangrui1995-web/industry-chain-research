## 结论先行

三环集团可以补入 AI server 高端 MLCC / X6S / AI power passives 跟踪池，当前定位为 `更偏基本面主受益候选`，不是已经确认的 AI server 大客户、料号、订单或涨价兑现标的。

可写入的逻辑是：AI ASIC / accelerator 板卡功率上升，推动小尺寸、高容、高温、高可靠 MLCC 需求上行；仓库既有 MLCC 次主线材料已经把三环集团排在“基本面质量优先、证据加权业绩弹性靠前”的位置。公司侧可确认的支撑来自既有备忘录整理：2025 年报披露产品应用于数据中心，已推出多尺寸高容 MLCC 和面向 48V 电源系统的多规格高容 MLCC；2026Q1 收入、利润增长与 MLCC 产品客户认可度提升、光通信需求增长有关。

必须保留的边界是：目前仍缺 AI server / ASIC 客户名单、具体 X6S 或高容高温料号、订单金额、交期、ASP、AI server 收入拆分和毛利率拆分。不能把 TrendForce、J.P. Morgan 或 Rubin 价值量材料里的行业需求上行，直接写成三环集团已拿到客户订单或高端 MLCC 已涨价兑现。

## 最大风险

最大风险是把“AI server 高端 MLCC/X6S 需求上行”直接等同于三环集团订单。当前可以确认的是公司具备数据中心高容 MLCC、48V 电源系统高容 MLCC 和 MLCC 客户认可度提升线索；不能确认具体 AI server 平台、CSP ASIC、GPU board、switch board 或 power shelf 客户订单。

第二个风险是把海外或行业侧涨价、交期和 TAM 估算当成三环 ASP 或毛利已兑现。没有公司公告、IR、财报分产品数据、客户公开材料或多源交叉前，涨价幅度、交期拉长、订单排期和毛利改善都只能作为后续核验问题。

第三个风险是普通 MLCC 周期复苏与 AI server 高端规格混同。若后续只看到普通 MLCC 景气或消费电子修复，而没有高容、高温、48V、电源完整性相关收入和毛利闭环，本卡维持 `evidence_gap_card`。

## 后续跟踪指标

1. 是否披露 AI server / ASIC / GPU board / switch board / 48V power shelf 客户类型、客户认证阶段、订单金额或批量交付规模。
2. 是否披露高容值、小尺寸、高温 X6S、高可靠、低 ESL / 低 ESR MLCC 的具体规格、良率、交期、产能利用率和料号。
3. 是否披露数据中心高容 MLCC 与 48V 电源系统 MLCC 的收入占比、ASP、涨价执行、毛利率或净利率贡献。
4. 2026H1 / H2 财报中电子元件、MLCC、光通信陶瓷和 SOFC 是否继续贡献收入、利润和现金流增量。
5. 应收、存货、合同负债、资本开支和在建工程是否支持真实订单扩张，而不是只反映行业预期和交易热度。
6. 若后续只有 TrendForce、券商、邮件或社媒线索，而没有公司客户、料号、ASP、收入和毛利闭环，则不升 `main_candidate`。
