## 当前结论

东芯股份本次从“国产存储观察 / 国产存储芯片-NAND”上调为 `AI memory hierarchy / reliable small-capacity memory formal_observation`，公司层分层为 `formal_observation / weaker_technical_watch`。

对应节点是 `SLC NAND + NOR / 中小容量高可靠存储`。其直接度在 SLC NAND/NOR 侧更清楚，适合跟踪小容量存储结构性紧缺、产品价格上行和盈利拐点；但交易层弱于兆易创新和普冉半导体，仍需要等待更清晰的客户、长单、ASP 和产品结构验证。

## 为什么不升主线

- SLC NAND 涨价和公司扭亏能证明小容量存储周期兑现，但不能直接等同 enterprise SSD、HBM 或 LPDRAM 主堵点。
- 当前缺 eSSD/AI server 直接客户、LTA、容量认证、产品结构拆分和 AI server 直接收入证据。
- 交易层尚未得到趋势确认，不能用“存储涨价”直接替代客户结构和订单可见度。

## 三层分级

| 层级 | 当前判断 | 依据与边界 |
|---|---|---|
| 基本面质量 | 中 | SLC NAND/NOR 暴露直接度较高，Q1 报告确认中小容量存储结构性紧缺、产品价格大幅攀升。 |
| 业绩弹性 | 中高 | 2026Q1 营业收入 4.79 亿元，毛利率 53.17%，归母净利 1.38 亿元并同环比扭亏。 |
| 交易弹性 | 中 / 等待企稳 | 邮箱战报和周报均提示短期走势弱于前两者，交易层需等待趋势修复或新增硬证据。 |

## 后续必须跟

1. SLC NAND、NOR 分产品 ASP、毛利率、库存天数和现金流是否继续改善。
2. 工业、汽车、高端网络、server boot/buffer 等客户结构是否有更明确披露。
3. 是否出现长单、选择性接单、客户预付款、交期拉长或订单可见度提升。
4. eSSD/AI server 直接客户、AI server 直接收入和容量认证证据目前为 `N/A`，有披露才允许上修。
5. 若产品价格回落、客户补库结束或毛利率回落，降回 `theme_adjacent/watch`。
