## 当前结论

联动科技本次定位为 `ai_soc_test_equipment_watch / hbm_test_chain_lead_only / event_trade_watch`，不进入 `main_candidate`。

链条层面，`HBM final/package test / memory probe card / Cube Prober / handler` 已在 AI 链状态中升为 `watch_to_soft / soft_bottleneck_candidate`。2026-06-22 08:53 邮件新增韩国 TSE 下一代 HBM handler 检测速度提升 2 倍线索，进一步说明 HBM 测试节拍、handler、die-level test 和探针/ATE 负荷在上行。

公司层面，联动科技公开披露的硬证据主要落在半导体自动化测试系统、功率/数模混合/SoC 测试、KGD、探针台和 AI SoC 测试机 QT-9800/QT-9800EXA；2026-06-04 投资者关系记录披露 QT-9800EXA 已与天数智芯签订战略合作协议，并继续推动 AI 芯片设计企业验证和量产应用。上述可以证明公司有 AI 算力芯片测试客户导入线索，但仍不能证明公司已有 HBM 客户、HBM handler、HBM probe card、memory probe card、订单、收入、ASP 或毛利兑现。

因此，核心写法是：`HBM 测试/探针链景气抬升` 可以提高联动科技的验证优先级；但联动科技当前硬证据是 AI SoC/功率/数模测试系统和客户导入，不是 HBM 探针卡或韩国 TSE handler 同节点订单。

## 最大风险

最大风险是把“HBM 测试链升级”误写成“联动科技已经拿到 HBM test/probe/handler 订单”。当前公开证据更偏 AI SoC 测试、功率/数模混合测试、KGD 和探针台，不等同于 memory probe card，也不等同于 TSE handler 或 Techwing Cube Prober 的同节点受益。

次要风险包括：天数智芯战略合作是否转化为采购订单、验收、收入和回款尚未披露；QT-9800EXA 量产后的毛利率仍是管理层努力方向而非已兑现数据；若市场把探针台、探针卡、handler 和 ATE 混成一个节点，估值和交易拥挤风险会放大。

## 后续跟踪指标

1. 公司是否披露 QT-9800/QT-9800EXA 的正式订单、验收、收入确认、回款和毛利率。
2. 天数智芯合作是否从战略协议升级为采购合同、联合验证结果、量产应用或收入贡献。
3. 公司是否披露 HBM、DRAM、memory probe card、probe card、handler、Cube Prober 或内存厂客户相关订单。
4. 半导体自动化测试系统收入中，AI SoC、KGD、功率器件、数模混合、探针台的拆分是否出现。
5. 2026H1/H2 财报端跟踪收入增速、毛利率、研发费用率、存货、合同负债、应收账款和经营现金流，判断订单是否真实转化为利润和现金流。
6. 若后续仍只有 HBM 行业景气、TSE/Techwing/FormFactor/Teradyne 海外线索，而无联动科技同节点订单/收入拆分，则维持 `hbm_test_chain_lead_only`，不升主线。
