## 结论先行

## 最大风险

最大风险是把“AI server 高端 MLCC 需求增加”和“AMD MI450 / NVIDIA 平台 BOM 升级”直接写成风华高科订单。当前只能确认风华高科存在 AI 服务器应用、高容 MLCC、客户编码和批量交付线索；不能确认直接供货英伟达，也不能确认 AMD MI450、CSP ASIC 或其他 AI server 大客户订单。

第二个风险是把邮件里的毛利率、订单排期和涨价幅度当成公司披露。没有公司公告、IR、客户披露、财报分产品数据或可信 B 级来源交叉前，这些只能作为后续核验问题。

## 后续跟踪指标

1. 是否披露 AI server / GPU board / switch board / power shelf 相关客户类型、客户编码数量、订单金额或批量交付规模。
2. 是否披露高容值、高可靠、低 ESL / 低 ESR MLCC 的具体规格、良率、交期、产能利用率和客户认证进展。
3. 是否出现公司或客户确认的 AMD MI450、CSP ASIC、NVIDIA 或其他 AI server 平台供货证据；没有前一律按 `N/A`。
4. 2026H1 / H2 是否披露高端 MLCC ASP、涨价执行、收入占比、毛利率或净利率改善。
5. 应收、存货、合同负债和资本开支是否支持真实订单扩张，而不是只反映交易热度。
6. 若后续只有行情上涨和邮件 / 社媒线索，而无客户、ASP、收入和毛利闭环，则维持 `high_trading_elasticity_watch`，不升 `main_candidate`。
