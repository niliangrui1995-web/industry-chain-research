## 当前结论

普冉半导体本次补入 `AI memory hierarchy / reliable small-capacity memory formal_observation`，公司层分层为 `formal_observation / earnings_elasticity_leader`。

对应节点是 `NOR + EEPROM + MCU / 小容量高可靠存储`。本次确认的核心变化是：公司小容量存储纯度较高，Q1 利润弹性已兑现，且邮件与周报均把它列为正式观察层里业绩弹性最强的一只；但缺 AI 数据中心客户或长单证据前，仍不能升为主受益。

## 为什么不升主线

- 普冉的优势在小容量存储价格上行、单价提升和规模效应，不是 HBM/LPDRAM/eSSD 对 AI server 出货的直接约束。
- 当前缺 AI 数据中心客户、AI server 直接收入、LTA、容量认证、分产品 ASP 和客户结构硬证据。
- 高业绩弹性不等于基本面质量第一，也不等于可以跳过估值、拥挤度和波动风险。

## 三层分级

| 层级 | 当前判断 | 依据与边界 |
|---|---|---|
| 基本面质量 | 中 | 小容量存储纯度较高，但仍需产品结构、客户质量和收入持续性验证。 |
| 业绩弹性 | 高 / 组内最高 | 2026Q1 归母净利 2.51 亿元，同比 +1,259.87%；单价提升和规模效应共同拉动。 |
| 交易弹性 | 高 / 需控拥挤 | 科创板小容量存储弹性强，但波动、估值和拥挤度需另查；缺直接 AI 客户前只作观察层交易弹性。 |

## 后续必须跟

1. NOR、EEPROM、MCU 分产品 ASP、毛利率、库存天数和现金流是否在 2026H1/H2 延续。
2. AI 服务器、终端设备容量升级、车规/工业/高端网络客户结构是否有正式拆分。
3. 是否出现 LTA、选择性接单、客户预付款、交期拉长或订单可见度提升。
4. AI 数据中心客户、AI server 直接收入和容量认证证据目前为 `N/A`，有披露才允许上修。
5. 若小容量存储报价回落、客户补库结束或毛利率回落，降回 `theme_adjacent/watch`。
