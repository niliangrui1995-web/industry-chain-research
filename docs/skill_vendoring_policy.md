# 技能副本维护策略

Last verified: 2026-06-25

本项目保留本地 skill 和插件副本两类内容。它们的存在是为了本地投研工作流可复现，不代表两边都可以随手修改。

## 文档技能边界

| 路径 | 角色 | 维护规则 |
|---|---|---|
| `skills/docx` | 项目本地 Word 入口副本。 | 只在本项目需要调整 Word 工作流时改动。 |
| `skills/pdf` | 项目本地 PDF 入口副本。 | 只在本项目需要调整 PDF 工作流时改动。 |
| `skills/pptx` | 项目本地 PPT 入口副本。 | 只在本项目需要调整 PPT 工作流时改动。 |
| `skills/xlsx` | 项目本地 Excel/CSV 入口副本。 | 只在本项目需要调整表格工作流时改动。 |
| `plugins/document-skills` | 插件来源副本。 | 视为 vendored plugin copy；没有专项升级计划时不手改。 |

## 默认规则

- 不因体积重复而直接删除任何 document skill。
- 不在没有专项计划时同时修改本地入口副本和插件副本。
- 如果必须同步插件能力，先记录来源版本、变更原因、受影响入口和验证命令。
- 如果只修本项目路由或说明，优先改顶层 manifest、README 或本地入口副本，不改插件副本。
- 健康检查只报告重复副本和边界状态，不自动清理。
