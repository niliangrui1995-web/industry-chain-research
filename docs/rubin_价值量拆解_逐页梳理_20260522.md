报告标题：`Greater China Technology Hardware: Analysis of Rubin rack BOM, component content, and ODM value-added`

报告日期：2026-05-20；PDF 共 18 页。第 1-11 页是核心内容，第 12-18 页主要是披露、评级定义和覆盖公司列表。

## 结论先行

这份报告的核心不是单纯说 Rubin 机架更贵，而是说明 AI 机架从 GB200/GB300 到 VR200 后，价值量从 GPU 单点扩散到内存、PCB、MLCC、ABF、电源、液冷和 ODM 组装测试。

最值得跟踪的投资主线：

1. **PCB/高层板/HDI/高速交换机板/中平面板**：报告中下游组件增幅最高，VR200 每机架 PCB 价值量从 GB300 的约 3.51 万美元提升到约 11.67 万美元，增幅约 233%。这是最能映射到 A 股硬证据公司的环节。
2. **高速 CCL 与上游材料**：报告明确提到 CCL 等级从 M7 继续升级到 M8，且 Rubin 计算板、交换板层数提升。这个变化利好高端覆铜板和低损耗材料供应商。
3. **800VDC/HVDC 电源架构**：报告给出电源价值量 +32%，且提到 Delta 与至少三家美国 CSP 推进 ASIC 电源机架项目。NVIDIA 官方也把 800VDC 定义为 2027 年起支撑 MW 级机架的方向。
4. **ODM 绝对毛利额提升**：市场担心标准化压低 ODM 价值，但报告估算 ODM 每机架附加值从 10.82 万美元升至 14.96 万美元，增幅约 38%。虽然毛利率从约 2.7% 降至约 1.9%，但绝对毛利美元额提升。
5. **ABF、MLCC、液冷、连接器是二级机会**：ABF 和 MLCC 百分比增幅大，但单机架美元增量不如 PCB；液冷的机内增量只有约 12%，但渗透率和机架热密度仍有长期驱动；连接器、线缆和高电流互连需要看具体客户与产品认证。

## 报告逐页梳理

### 第 1 页：摘要和核心观点

报告估算，超大规模云客户从 ODM 采购 Rubin 机架的价格约为 780 万美元；若从 OEM 厂商采购，价格更高。下游组件中，PCB、MLCC、ABF、电源和散热系统的内容量都提升。

关键数字：

| 环节 | 报告估算增幅 |
|---|---:|
| PCB | +233% |
| MLCC | +182% |
| ABF 基板 | +82% |
| 电源 | +32% |
| 散热系统 | +12% |
| ODM 附加值 | +35%-40% |

报告观点：投资者不应只看 ODM 毛利率下滑，因为机架 ASP 大幅提高后，ODM 绝对毛利额仍在增加。

### 第 2 页：VR200 机架 BOM 和内存占比

报告估算 VR200 机架总成本约 780 万美元。上升主因之一是内存价格和内存内容量提高。GB200 NVL72 时，内存成本只占 BOM 约 5%-10%；到 VR200，内存成本占比升至约 25%-30%。GPU 成本占比则从 GB200 的约 65% 降至 VR200 的约 51%。

报告还提出一个重要情景：如果大型客户直接采购 SOCAMM 设备，Rubin 机架 ASP 可能从约 780 万美元降至约 670 万美元。这个变化对 ODM 的收入确认、营运资金和毛利率都会有影响。

### 第 3 页：GB200、GB300、VR200 的总 BOM 对比

报告估算：

| 机架 | ASP/BOM 估算 |
|---|---:|
| GB200 NVL72 | 3,329,523 美元 |
| GB300 NVL72 | 3,994,551 美元 |
| VR200 NVL72 | 7,803,148 美元 |

VR200 相对 GB300 总额增幅约 95%。分项看，最大美元增量来自 GPU 和内存，但下游可投资组件里，PCB 的增幅最突出。

| 分项 | GB300 | VR200 | 增幅 |
|---|---:|---:|---:|
| GPU | 2,520,000 | 3,960,000 | +57% |
| NVLink 交换芯片 | 64,800 | 144,000 | +122% |
| 其他网络芯片 | 261,000 | 576,000 | +121% |
| 内存 | 373,939 | 2,001,600 | +435% |
| 冷却 | 64,610 | 72,080 | +12% |
| 电源 | 57,600 | 76,000 | +32% |
| PCB | 35,100 | 116,730 | +233% |
| ABF | 11,160 | 20,340 | +82% |
| MLCC | 1,530 | 4,320 | +182% |
| 机架组装增值 | 22,400 | 28,800 | +29% |

### 第 4 页：PCB 是下游组件里最强的价值量扩张

报告把 PCB 增量拆得很细：Rubin 的 PCB 总价值量约 11.67 万美元，而 GB300 约 3.51 万美元。主要原因包括：

- PCB 数量增加：新增 Midplane PCB、BlueField PCB、ConnectX PCB 等模块。
- 层数提升：Rubin 计算板使用 26L，而 GB300 采用 22L HDI PCB。
- CCL 等级提升：Blackwell 相关 CCL 等级从 M7 升至 M8。
- 交换托盘升级：Rubin 交换托盘 PCB 升级为 32 路，而 Blackwell 为 24 路。
- 计算托盘新增 44L Midplane PCB。

每机架 PCB 价值量拆分：

| PCB 类型 | GB300 | VR200 |
|---|---:|---:|
| Compute/打印 PCB | 23,400 | 50,400 |
| Switch PCB | 7,200 | 13,050 |
| Midplane PCB | 0 | 27,000 |
| BlueField PCB | 0 | 4,590 |
| ConnectX PCB | 0 | 19,440 |
| 其他外围 PCB | 4,500 | 2,250 |
| 合计 | 35,100 | 116,730 |

投研含义：这是全报告最重要的 A 股映射点。应优先找高层板、HDI、AI 加速卡、交换机板、中平面板和高速材料验证能力强的公司。

### 第 5 页：MLCC 和 ABF 的增量

VR200 每机架 MLCC 价值量约 4,320 美元，GB300 约 1,530 美元，增幅约 182%。报告解释了 ODM 积极抢购和扩库存的原因：2026 年下半年 Rubin 机架产能提升前，AI 服务器 MLCC 需求已经明显紧张。

MLCC 拆分：

| 模块 | GB300 | VR200 |
|---|---:|---:|
| Compute PCB | 900 | 3,240 |
| Switch PCB | 180 | 405 |
| BlueField DPU 模块 | 0 | 90 |
| ConnectX 模块 | 0 | 360 |
| 其他外围 PCB | 450 | 225 |
| 合计 | 1,530 | 4,320 |

ABF 的增量来自两个方向：一是 GPU/CPU 等单颗芯片基板 ASP 提升，二是 NVLink、ConnectX 等芯片数量增加。报告引用的估算是 Rubin GPU ABF 基板 ASP 约 200 美元，Blackwell 约 100 美元。

### 第 6 页：ABF 细项和电源路线

ABF 每机架价值量从 11,160 美元升至 20,340 美元，增幅约 82%。

| ABF 项目 | GB300 | VR200 |
|---|---:|---:|
| GPU | 7,200 | 14,400 |
| CPU | 1,800 | 2,160 |
| NVSwitch ASIC | 540 | 1,080 |
| BlueField DPU | 540 | 540 |
| ConnectX | 1,080 | 2,160 |
| 合计 | 11,160 | 20,340 |

电源部分，报告提到 Vera Rubin 标配 110kW 电源机架；某美国 CSP 已采用 HVDC 独立式电源机架；Rubin Ultra 预计 2027 年下半年采用 800VDC 供电方案；Delta 正与至少三家美国 CSP 客户在 ASIC 电源机架项目中推广 HVDC，初步部署计划在 2026 年下半年。

投研含义：电源不是单纯 PSU 增量，而是从机架内供电升级到数据中心级 HVDC 架构，重点看 800VDC、±400VDC、rack power shelf、busbar、保护器件、SiC/GaN 和系统集成。

### 第 7-8 页：液冷和 ODM 附加值

液冷部分，报告认为 Vera Rubin 服务器机架将采用全液冷设计，无风扇结构提升散热效率。每机架冷却价值量不含侧车 CDU 从 64,610 美元升至 72,080 美元，增幅约 12%；若计入侧车 CDU，总冷却量从 114,610 美元升至 122,080 美元。

注意：液冷方向长期确定，但这份报告里的“单机架增量”不算最高。若市场只按液冷主题交易，需要警惕预期过满。

ODM 附加值是报告的另一个反共识点。市场原本认为计算托盘标准化会压低 ODM 价值，但报告估算 VR200 反而因系统复杂度和新增模块组装测试，ODM 附加值提升约 38%。

| ODM 附加值项目 | GB300 | VR200 |
|---|---:|---:|
| 计算板组装/测试 | 12,096 | 16,200 |
| 计算托盘组装/测试 | 28,800 | 32,400 |
| 交换机板组装/测试 | 2,475 | 3,150 |
| 交换机托盘组装/测试 | 2,700 | 3,150 |
| 机架组装/测试 | 22,400 | 28,800 |
| BF DPU 组装/测试 | 1,170 | 1,170 |
| CX 模块组装/测试 | 0 | 3,600 |
| 冷却部件 | 12,922 | 14,416 |
| 其他 | 22,500 | 45,500 |
| ODM 总附加值 | 108,213 | 149,646 |

毛利率视角：GB300 约 2.7%，VR200 约 1.9%。但绝对毛利美元额从约 10.82 万美元升至约 14.96 万美元。

### 第 9-10 页：ODM 出货、估值和 AI 暴露

报告展示 GB200/GB300 NVL72 机架产出爬坡：从 2025 年初到 2026 年 4 月，主要 ODM 月度产出明显提升。季度口径中，2026 年二季度估算达到 24.9 千台，之后进入切换期。

AI 收入暴露估算：

| ODM | CY25 | CY26E |
|---|---:|---:|
| 鸿海 | 27% | 32% |
| 广达 | 50% | 68% |
| 纬创 | 27% | 35% |
| Wiwynn | 48% | 44% |
| 仁宝 | <3% | 8% |
| 和硕 | <3% | 22% |

报告认为 ODM 年初以来明显跑输 TAIEX，估值并不算过热。报告偏好顺序：Wiwynn、Wistron、Quanta、Hon Hai。

### 第 11 页：ODM 估值表

报告列出主要 ODM 的 2026-2028 年 EPS、PE、PB、PS、EV/EBITDA、ROA、ROE 和目标价。核心信息：

- 平均 2026E PE 约 13.8 倍。
- 平均 2027E PE 约 11.2 倍。
- 平均 2028E PE 约 9.9 倍。
- Wiwynn、Wistron、Quanta、Hon Hai 均为超配。

投研含义：ODM 不是最高弹性的环节，但如果市场仍用传统低毛利制造业逻辑给估值，Rubin 带来的绝对利润额提升和委托/代工模式改善营运资金，可能带来估值重估。

### 第 12-18 页：披露与覆盖列表

后半部分主要是摩根士丹利的利益冲突披露、评级定义和覆盖公司清单。对投研有用的信息有两点：

- 披露显示摩根士丹利与部分覆盖公司存在投行业务或持仓关系，必须把报告作为卖方估算来源，而非独立事实。
- 覆盖列表给出了报告相关的大中华区硬件公司范围，包括台达电、AVC、FIT、Unimicron、ZDT、Wiwynn、Wistron、Quanta、Hon Hai，以及 A 股的沪电股份、深南电路、生益科技、工业富联、立讯精密等。

## 后续跟踪指标

1. Rubin VR200/NVL72 的 2026 年下半年量产节奏：Q2 样品、Q3 确收、Q4 爬坡是否兑现。
2. PCB：高层板层数、M8/M9 CCL 认证、Midplane/Switch/ConnectX/BlueField 板订单、泰国/越南产能良率。
3. CCL：M7/M8/M9 价格、覆铜板涨价是否顺利传导、低损耗材料进口替代。
4. ODM：客户是否转向委托/代工模式、SOCAMM 是否由客户直采、营运资金压力是否下降、绝对毛利额是否提升。
5. 电源：800VDC、±400VDC、HVDC power shelf、busbar、保护器件是否进入实际部署和收入确认。
6. MLCC：AI server 规格升级是否带来供需紧张、日系/台系涨价、国产厂商是否有明确 AI server 客户验证。
7. 液冷：CDU、冷板、歧管、QD 的客户项目和单机架价值量，避免只看渗透率。
8. 估值与交易：A 股 PCB/液冷/电源链的 PE、换手率、融资余额、相对 20/60 日涨幅，防止基本面正确但交易过热。
