VR-NVL72 vs GB300/GB200 BOM 增量节点账本

这份 HTML 按 Public Equity 投研备忘录方式重排：先给研究优先级、决策铰链和否定条件，再展开 BOM 增量、A 股映射、交易弹性和来源账本。核心纪律是只保留能落到具体物料、客户认证、订单、收入或毛利传导的标的。

第一主线：PCB / CCL / 电子布 强旁线：光通信 条件式观察：铜箔 / 连接器 / 电源 / 液冷 剔除：泛概念、泛 retimer、泛液冷
结论：VR-NVL72 相对 GB300/GB200 不是 GPU/CPU 数量增加，而是 NVLink、NVSwitch、CX9 与板级互联继续升级。A 股最强弹性不在 NVIDIA 互联芯片本身，而在高速互联外溢到 PCB、CCL、电子布、低粗糙度铜箔和连接结构后的价值量、良率和认证门槛。

PM 先读层

研究立场

优先级：PCB/CCL/电子布仍是 VR-NVL72 单柜 BOM 增量最清晰的 A 股主线；连接结构、电源和液冷是二线，必须靠订单和收入拆分升级；光通信景气度强，但应单独建账，不混入 VR 柜内 BOM 主线。

决策铰链

关键不是“新一代 GPU 数量更多”，而是“同样 72 GPU / 36 CPU 下，互联带宽、switch tray、CX9 module 和 midplane 把板级材料复杂度推高”。

必须成立

  • PCB 价值量 +233% 能转化为高层板、HDI、midplane、ConnectX PCB 的订单和毛利。
  • M8/M9 CCL、低介电电子布、PCB 级 HVLP/RTF 铜箔出现涨价、交期拉长或客户锁料。
  • 连接结构、电源、液冷标的能拿出 AI rack 平台认证、客户、收入或毛利拆分。

否定条件

  • AI PCB 订单递延、毛利率下行、应收和存货失控。
  • 高端 CCL / 电子布交期回落，二供 AVL 快速扩容，涨价停止。
  • 标的只能讲概念，不能回答“供应哪个物料、用在哪个节点、如何进收入/毛利”。

三层排名

基本面质量

  1. 沪电 / 生益 / 深南：证据质量、客户验证和财务韧性更强。
  2. 胜宏：成长和兑现最强，但资本开支和客户不透明度高。
  3. 中际 / 新易盛：光模块旁线质量强，不归入 VR 单柜主线。
  4. 生益电子：PCB 纯度高，体量和披露仍需验证。
  5. 宏和 / 鼎通 / 德福：节点弹性高，证据边界和估值风险更大。

业绩弹性

  1. 胜宏：PCB 价值量 +233% 的直接映射，已有高端 HDI/高层板兑现。
  2. 宏和：高端电子布收入与毛利弹性高，但估值和周期反转风险极高。
  3. 德福：HVLP4/5 与头部 CCL 合作转正式订单后弹性大。
  4. 鼎通：224G/CAGE/液冷结构件兑现会有弹性，但不是芯片主线。
  5. 沪电 / 生益电子 / 深南 / 生益：更稳，但预期更充分。

交易弹性

  1. 鼎通 / 德福 / 国际复材：小市值、高换手、高主题弹性，但证据更脆弱。
  2. 宏和：电子布最强题材之一，但 PE 与涨幅已经很危险。
  3. 胜宏：高成交、高关注、高兑现，仍是主线交易核心。
  4. 光迅 / 源杰 / 天孚：光通信旁线弹性强，不是 VR 柜内主增量。
  5. 沪电 / 生益 / 深南 / 中际 / 工业富联：中军属性更强，弹性被市值摊薄。
