# A 股数据源自动路由

本文件规定项目内投研取数的自动拆解和选源方式。它只决定数据任务如何分卡、选择哪一个主源以及何时可等价回退；不替代领域 Skill，不把厂商数据升级为官方事实，也不构成投资结论。

## 先拆解，再取数

涉及外部或本地数据时，先在内部形成最小 `data_request_plan`，用户无需手动指定供应商。每张数据卡至少固定：

- `field`、标的/市场、`as_of`、日期区间和频率；
- 单位、币种、复权、会计、市值总/流通等口径；
- `evidence_tier`：`official_evidence`、`vendor_snapshot`、`historical_series` 或 `derived_metric`；
- `primary_source`、有序 `fallback_source`、回退条件和是否需要 `financial-evidence-audit`。

不同日期、口径或证据等级不得混成一张卡。相同来源、相同口径的卡可合并为一次请求。先做最小、只读的能力与字段探测；HTTP 成功但业务信封失败、字段缺失、日期不覆盖或单位/定义不一致，均不算可用。主源不满足时才按回退顺序继续，禁止为了“完整”无差别调用所有供应商。

每张卡至少在任务运行状态或相应审计产物中保留 `field`、`as_of`、定义、主源、回退源、探测结果和实际回退原因。用户明确限定来源时优先遵从；领域 Skill、自动化合同和受控产物的硬性来源规则优先于本文件。自动化任务必须先完成其合同规定的预检和元数据门，本路由只在预检通过后、首次业务读取前生效。

## 字段驱动的选源

| 数据卡 | 主数据源 | 等价回退 | 关键边界 |
|---|---|---|---|
| 公告、定期报告、公司客户/订单/收入等可作事实依据的材料 | 公司 IR、CNINFO、交易所或监管原文 | 可核对到原文的厂商索引 | 厂商数据只能发现或复核线索，不能替代原文；收入以定期报告等原文核验，订单若只见管理层表述则标为 `management_claim`。 |
| 标的/代码消歧 | `hithink-finance` 元数据 | iFinD → 东方财富妙想 → TDX | 先取得唯一证券标识；无法唯一消歧时再向用户确认。 |
| A 股最新价、成交、复权日线、最新 PE/PB、指数/板块或公募基金的结构化厂商数据 | `hithink-finance`，前提是最小探测证明字段和时点可用 | iFinD；用户指定本地数据时为 HT/TDX | 标注厂商、快照时点、复权和单位；不得写成官方披露。 |
| 跨市场、宏观、新闻、债券或 iFinD 已覆盖的宽口径证券/基金数据 | iFinD，前提是实际授权请求可用 | `hithink-finance`（仅在其能力范围内） | 不用相似字段冒充相同定义；同花顺当前不覆盖宏观、公告原文、债券、港美股。 |

| 本项目“融资余额占沪深总市值”网页分母 | 已受控的两段厂商链：`mx_pre2017_market_cap_vendor`（2011-08-03 至 2016-12-30）与 `eastmoney_post2017_market_cap_vendor`（2017-01-03 起） | 无临时换源；仅按对应构建合同更新或重建该受控链 | 两段都是东方财富厂商口径，且与 DFCF 分子未必严格证券类别匹配；该聚合比例不是正式财务比例。 |
| 个股历史总市值/流通市值 | 先探测东方财富妙想或 iFinD 是否返回所需历史日期、总/流通定义和原始字段 | 仅在字段、日期、总/流通口径等价时使用另一厂商；厂商均无数据后才按“尽量不使用官方”的偏好考虑官方链或报告 `source_gap` | 不得假定 `hithink-finance` 提供历史市值；TDX、HTSC 不得替代点时历史市值。 |
| 沪深两市日度两融余额 | 领域合同指定的 DFCF `RPTA_WEB_RZRQ_LSSH` | 无 | DFCF-only 自动化不得改用 iFinD、同花顺、TDX 或交易所请求；TDX 只可作本地交易日历哨兵。 |
| 技术指标、短期交易背景、题材/板块初筛 | 当前可用的 A 股行情厂商；本地要求优先 TDX/HT | 另一行情厂商 | 这些字段不能证明客户、订单、收入或产业链受益。 |
| 券商叙事、策略观点或辅助解释 | HTSC 等经验证的研究/叙事接口 | 其他可核验二级来源 | 不能作为精确行情、市值、财报或官方事实的唯一输入。 |

## 时间与口径默认值

- “最近收盘”默认最近一个**已完成交易日**的收盘价；用户明确要求“实时/盘中”时，另取并明确标为当前快照，不能把 `last_price` 写成收盘价。
- “近一年日线”默认以查询日向前的一个自然年；复权未指定时采用所选数据源的既有默认并明确披露。当前 `hithink-finance` 默认前复权；用户要求原始成交价格时使用未复权口径。
- “PE/PB”等最新估值属于厂商快照，必须单列快照时点；只有该值用于估值或投资结论时，才进入 `financial-evidence-audit`，普通行情查询不伪装成已审计估值结论。

## 选源排序和回退

对每个候选源依次检查：

1. 是否能返回该字段的同义定义，而不是近似指标；
2. 是否覆盖请求的标的、日期、频率和总/流通、复权、会计等口径；
3. 返回是否新鲜、可复现且业务成功；
4. 是否符合证据等级和当前项目/自动化合同；
5. 是否以更少的请求完成，并保留来源独立性。

主源失败时，记录失败阶段和原因，再尝试一个等价回退。所有候选都不满足时输出 `N/A`、`source_gap`、已尝试来源和可重试条件；不得用最新值填充历史缺口、用不同市场口径拼接，或静默沿用旧值。

## 准出与汇报

- 决策关键的市值、PE、预期差、单位换算和受审计器支持的比例/跨源数字，必须追加 `financial-evidence-audit`；未通过不得写为已核验结论。
- DFCF 两融余额/沪深总市值这类聚合代理若审计器返回 `UNSUPPORTED_RATIO_CONTRACT`，必须标为非正式比例和 `N/A` 审计状态，不得伪称通过。
- 同一结论若使用多源，逐字段保留 `source`、`as_of`、口径、单位和缺口，不能只在表尾笼统写“数据来自多源”。
- 仅在数据源选择会影响结果、发生回退或存在缺口时，向用户简要说明“主源 / 回退 / 原因”；普通任务不输出冗长路由日志。
